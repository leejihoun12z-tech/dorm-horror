# 밤 단계 = 일러스트가 기괴해짐 (2026-11-28, [후보] · 그리기 전)

사용자 11-28: 「공포 방향이 애매해 · 단계가 올라간다고 방이 되고 그런 게 아니라 **일러스트가 기괴해지는 쪽 + 연출**」 + 기괴 요소 목록(아래 §1).
→ 앞 문서들(`roster-redesign-20261128.md` §2·§4의 4단계 칸, `night-mutation-cast-20261127.md`)의 「방이 됨 · 허물이 걸어 다님 · 일벌이 된 기숙생」 같은 **개념 변신은 [폐기·대체]**. 단계마다 바뀌는 건 **캐릭터 그림 자체(얼굴·몸·비율)**.

## 0. 단계 (사용자 11-28)
| 단계 | 그림에서 바뀌는 것 | 얼굴 강도 |
|---|---|---|
| 1 인외 미소녀 | 인외 부위가 매력 포인트, 공포 없음 | 0 |
| 2 인외 강화 | 인외 부위가 커지고 많아짐 | 0~1 |
| 3 공포 추가 | 아래 요소 1~2개가 처음 나옴 — 주로 얼굴(역안·검은 동공·어색한 표정)·조금 늘어난 비율 | 상한 3 안 |
| 4 공포 극대화 | 요소 여러 개를 겹침 — 사실적인 눈·이빨, 찢어진 입, 괴물 혀, 많은 눈, 엉뚱한 곳의 이목구비, 극단 비율, 어울리지 않는 사실적 질감 | 예외 |
그림은 같은 캐릭터·같은 구도에서 단계만 올림(좀비 시험처럼). 4단계에도 실루엣의 표지(모자·마스크 등)는 남김.

## 1. 기괴 요소 (사용자 목록)
많은 눈 · 새까만 입 · 새까만 얼굴에 눈만 · 사실적인 눈 · 사실적인 이빨 · 기괴한 괴물 혀 · 찢어진 입 · 역안 · 기괴한 표정 · 기괴한 비율(팔·목·다리·머리가 늘어남) · 어색한 얼굴 · 크고 새까만 동공 · 많은 이빨 · 말도 안 되게 크게 벌어진 입 · 어울리지 않는 사실적 그림체와 애매하게 불쾌한 비율 · 이상한 위치의 눈코입·팔다리
