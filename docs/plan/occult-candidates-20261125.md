# 유명 귀신·요괴·오컬트 후보 (2026-11-25, 그리기 전 · [후보])

사용자 11-25: 「팔척귀신이나 사다코 같은 거 모에화 많이 하잖아, 유명한 귀신·요괴·오컬트 요소 찾아봐, 그리지는 말고」.

## 1. 왜 이쪽이 맞나
- 도시전설은 **원래 「규칙」이 붙어 있다** (「나 예뻐?」에는 애매하게 답하기, 셋째 칸은 세 번 두드리지 않기, 전화가 위치를 말하면 뒤돌아보지 않기). 우리 게임의 **나폴리탄 수칙·밤 순찰**과 그대로 이어진다.
- 팔척귀신·빨간 마스크·하나코처럼 **이미 모에화가 많이 된 것**은 이름만 들어도 알아서, 첫인상이 빠르다(팔척귀신은 큰 키·흰 원피스·모자 외에는 자유롭게 그려지고, 고양이 귀 모자 같은 변형도 있음 — 니코니코·pixiv 백과).
- 「물건 기반 + 공포 단계」 기준(inhuman-hair-plan §10)과도 맞는다: 마스크·가위·전화기·엘리베이터·소복·갓처럼 **상징 물건이 하나씩 붙어 있다**.

## 6. 다시 짠 리스트 — 「디자인만 보고 알아봄」 + 서브컬처식 재해석 (2026-11-25 3차) [후보]

사용자 11-25: 「캐릭터 디자인만 보고 어떤 건지 유추되고 확실한 디자인 요소가 들어갈 만한 것, 그대로 넣지 말고 서브컬처 게임처럼 디자인을 추가하는 방향」.

새 기준:
1. **상징 2~3개만 지키면 이름을 몰라도 알아봄** (실루엣·소품·옷 하나로)
2. 그 상징을 **현대 대학생 옷·역할·소품으로 다시 짤 여지**가 있음 (원전 그대로 소복만 입히지 않음)
3. 수칙 한 줄 · 저작권 문제 없음 · 지금 명단과 안 겹침
→ 정체가 규칙·소리뿐인 것(엘리베이터 게임·손톱 쥐·레이크·방문객·쿠네쿠네 등)은 **디자인으로 안 읽혀서 내림**.
