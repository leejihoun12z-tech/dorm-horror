# 배경 제작 방식 — "인형의 집 기숙사" (데포르메 형태 + 사실 조명)

_작성 2026-11-27 · 사용자: "진행하면 어떤 방식으로 제작해?"_
_전제: 배경 방향 ②(env-style-direction §3, [후보] — 사용자 확정 전) · 엔진 Godot 4.7(hq-environment-plan) · 품질 목표 C단(map-anomaly-and-quality). 모든 수치는 [작업값]._

## 1. 한눈에
**AI가 만들고, 규칙이 통일하고, 사람이 판단한다.**
```
기준 정하기(1회) → 모듈 키트 → 재질 → 소품 → 조립 → 조명 → 괴현상 자리 → 검사 루프 → 사용자 걷기
   사용자+Claude    Claude      Claude   Claude+Tripo  Claude  Claude→사용자    Claude      Claude        사용자
```
- **Claude**: Blender·Godot를 스크립트로 조작해 만들고, 고정 카메라로 찍어 스스로 비교·수정.
- **사용자**: 참고 그림 고르기 · 단계마다 "좋다/아니다" · 조명 최종 판단 · 직접 걸어 보기.
- **AI 도구**: Tripo Pro(구독 중) = 복잡한 소품 · ComfyUI/GPT = 소품 참고 그림·없는 재질 · Claude = 나머지 전부.

## 2. 단계별
### 0단계 — 기준 정하기 (한 번만)
| 만들 것 | 내용 |
|---|---|
| 참고 그림 3장 | 사용자가 고름(낮 복도·밤 복도·방 안). 모든 비교의 기준 |
| **데포르메 규칙표** | 아래 §3. Blender 스크립트가 자동으로 지킴 |
| 색·재질 표 | 벽·바닥·문·금속·천 5~8가지 재질 × 낮/밤 색 |
| 고정 카메라 5곳 | 복도 끝·사감실 문·방 안·계단·휴게실. 매번 같은 자리에서 찍어 비교 |
| 점검표 | hq-environment-plan §4 + paper-puppet-production §4-2(빛·생활감·얼룩·반사·공기·마무리·소리) |

### 1단계 — 모듈 키트 (Claude, Blender 명령줄 스크립트)
- 조각: 벽(2m·1m), 모서리(안·밖), 문틀 + 문(닫힘·열림·살짝 열림), 천장 패널 + 형광등 자리, 바닥, 창문, 걸레받이, 계단.
- 규칙: 2m 격자에 딱 맞음 · 원점은 바닥 모서리 · 라이트맵용 두 번째 UV 자동 · 이름 규칙(`wall_2m_a`) → glb로 내보냄.
- 이유: 같은 조각을 반복해야 **괴현상(복도 늘이기·반복 구간)**을 만들 수 있고, 2~4층도 조각을 다시 써서 빨라짐.

### 2단계 — 재질
- 기본: **사진 스캔 무료 재질**(Poly Haven·ambientCG, CC0) → 우리 색표로 색만 맞춤.
- 없는 것(한국 장판, 기숙사 문 시트지, 게시판 종이): 사진 촬영 또는 AI 재질 생성 → 손질.
- 데포르메: 무늬 크기를 실제보다 1.5배(타일·나뭇결이 커서 미니어처처럼 보임).

### 3단계 — 소품 (3갈래)
| 종류 | 예 | 만드는 법 |
|---|---|---|
| 단순한 것 | 신발장·사물함·게시판·소화기함·분리수거함·침대·책상·의자·우편함 | **Claude가 Blender 스크립트로 직접**(데포르메 규칙 자동: 두께·둥근 모서리) — 사례상 AI 생성보다 쓰기 좋음 |
| 복잡한 것 | 선풍기·전자레인지·소화기·인형·화분·옷걸이 | 참고 그림 1장 → **Tripo** → Claude가 Blender에서 정리(면 줄이기·UV·재질 다시·크기) |
| 흔한 것 | 컵·책·병·상자 | 무료 CC0 팩(Polyfork 등) → 재질·크기만 맞춤 |
- 소품마다 정면·측면을 고정 조명 아래 찍어 한 장 검수 그림으로 → 사용자가 한 번에 훑어봄.

### 4단계 — 조립 (Claude, Godot)
- 층 배치는 **데이터 표**(방 번호·문 상태·소품 목록)로 → 스크립트가 조각을 배치. 바꾸기 쉽고 괴현상이 표를 바꾸는 방식으로 들어감.
- 소품 1차 배치: 규칙으로 흩뿌림(방문 옆 신발, 게시판 종이 3~5장 등).
- **이야기 소품**(문 앞에 놓인 택배, 멈춘 시계 등): 사용자와 정해서 손으로.

### 5단계 — 조명 (Claude 1차 → 사용자 최종)
| | 낮 | 밤 |
|---|---|---|
| 주 조명 | 면 조명(AreaLight3D) 형광등 + 창빛 | 손전등(실시간 그림자) + 비상구 초록 불 + 창밖 가로등 |
| 간접광 | 라이트맵 굽기(LightmapGI) | 밤용 라이트맵 따로 굽기 [확인 필요: 메모리] |
| 공기 | 옅은 먼지 | 볼류메트릭 안개, 손전등 빛줄기 |
| 화면 | **얕은 피사계 심도(미니어처 느낌)** · 따뜻한 색 | 피사계 심도 끔 · 색 빼기 · 필름 입자 |
| 기타 | 반사 프로브(바닥 왁스), 데칼(얼룩·테이프 자국) | 깜빡이는 형광등 몇 개 |
- 빛 3종 원칙: 실제 광원 · 분위기 빛 · 시선 끄는 빛. 전부 어둡게가 아니라 **밝음과 어둠의 경계**.

### 6단계 — 괴현상 자리 (Claude)
- 조각 경계에 "바꿀 수 있는 지점"을 미리 둠: 복도 늘이기 끼움 자리 · 반복 구간 짝(조명까지 똑같이) · 포털 문 자리 · 안 볼 때 바꿀 소품 묶음.

### 7단계 — 검사 루프 (Claude, 자동)
1. 고정 카메라 5곳 → 참고 그림과 나란히 한 장.
2. **전 구역 걷기 측정**: 2m 격자 × 4방향으로 찍어 밝기·너무 밝은 곳·너무 어두운 곳을 숫자로(Scenario 사례: 과노출 397 → 17칸).
3. 프레임 측정(사용자 PC 기준 60fps).
4. 결함(부유·관통·잘림)은 바로 고침 → **한 번에 하나만 고치고 다시 찍음**.

### 8단계 — 사용자 걷기
- 직접 걸어 보고 "무섭다/답답하다/예쁘다" 메모 → 반영. 조작감·분위기는 이 단계 전엔 완료라고 하지 않음.

## 3. 데포르메 규칙표 [작업값 — 시험에서 고침]
| 항목 | 실제 | 우리 | 왜 |
|---|---|---|---|
| 벽 두께 | 0.15~0.2m | **0.3m** | 두툼한 모형 느낌 |
| 모서리 | 각짐 | **둥글게 3~5cm** | 손으로 만든 미니어처 |
| 문 높이 | 2.0~2.1m | **2.3m** | 살짝 큰 세상 |
| 손잡이·스위치·콘센트 | 1배 | **1.5배** | 인형의 집 소품 느낌, 상호작용 물건이 잘 보임 |
| 천장 높이 | 2.4~2.6m | **2.8m** | 공간에 여유, 밤에 위가 어두움 |
| 복도 폭 | 1.8~2.4m | 2.6m | 종이 카드와 함께 서도 답답하지 않게 |
| 수직선 | 반듯 | **0.5~1° 어긋남** 일부 | "조금 틀린" 느낌 — 밤에 더 심해짐 |
| 재질 무늬 크기 | 1배 | **1.5배** | 미니어처 |

## 5. 순서와 대략 기간 [작업값]
1. **복도 한 칸 시험 A/B** — 같은 복도를 "사실 비율"과 "데포르메 비율" 두 벌 + 종이인형 카드 → 비교 → 방향 확정. (PC 2~4일)
2. 1층 전체 — 사감실·복도·방 4·휴게실·세탁실. (1~2주)
3. 낮/밤 조명 두 벌 + 괴현상 2개(늘어나는 복도·반복 구간). (약 1주)
4. 2~4층 — 1층 키트·재질 재사용, 층마다 다른 점만. (층당 수일)
- 기간은 사례(방 하나 수 시간~수일) 기준 추정이며, 사용자 확인 속도에 따라 달라짐.

## 6. 미리 정할 것
1. 배경 방향 ② 확정 여부(복도 A/B 시험 뒤 확정도 가능).
2. 참고 그림 3장.
3. 한국 기숙사 사진 — 직접 찍을 수 있으면 재질·소품 목록의 기준으로 가장 좋음.
4. AI 사용 고지: 스팀 공개 문구에 "3D 소품 일부·재질 일부 AI 생성 후 손질" 정직하게.
