## 3. 기숙생 6명 다시 짜기 [후보 — 사용자 결정]
기존 6명(concept §6)을 규칙 R1~R7로 다시 본 것. ◎ = 레퍼런스 방향에 잘 맞음.

| 종족 | 낮 훅 (R1) | 색 (R2) | 스위치·밤 (R3·R7) | 게임 장치와 연결 | 판정 |
|---|---|---|---|---|---|
| 흡혈귀 | 깨진 손거울 조각을 머리 장식·귀걸이로 (자기 얼굴을 찾으려 모음, 아무것도 안 비침) | 검정·와인·은 + 붉은 눈 | 거울 조각마다 그녀의 눈이 비치기 시작 → 몸에 거울 금 | 기숙사 거울 = 이상현상 | ◎ 유지 |
| 슬라임 | 반투명 배 속에 삼킨 사탕·열쇠·머리핀이 떠 있음 | 민트·흰색 + 분홍 | 배 속 물건이 남의 물건 → 남의 얼굴 | 분실물 = 이상현상 | ◎ 유지 |
| 구미호 | 머리 옆에 비스듬히 쓴 여우 축제 가면 + 꼬리 9개 | 흰·주홍·검정 | 가면을 얼굴에 쓰면 가면이 진짜 얼굴 (R7) | 꼬리 수 세기 | ◎ 유지 |
| 안드로이드 | 얼굴 판 이음선 + 귀 대신 센서 | 흰·회색 + 청록 | 얼굴 판이 열리고 안에 사람 눈 | 같은 말 반복 | ○ 훅이 약함 |
| 라미아 | 담요를 두른 졸린 언니 + 뱀 꼬리 | 갈색·크림 + 노랑 눈 | 허물이 사람 모양으로 걸어옴 | 허물 = 흔적 | ○ 3D 하반신 부담 |
| 구체관절 인형 | 관절 이음선 + 등의 실패(실 감는 통) | 하양·검정 + 빨간 실 | 실이 늘어나 거미처럼 | 인형 개수 | ○ 흡혈귀(고딕)와 겹침 |
| **강시** (새) | 앞머리에 핀처럼 꽂은 부적 + 세일러 교복 | 남색·흰색 + 노랑 부적 | **부적이 떨어지면 변함** (R7) | **부적 = 기숙사 수칙 종이와 같은 재료** — 규칙 괴담과 바로 이어짐 | ◎ 추천 |
| **나방** (새) | 털 더듬이 + 숄처럼 두른 날개 | 흰·회색 + 빨강 눈 | 빛을 보면 끌려옴, 날개 가루 | **손전등을 켜면 다가옴** — 밤 순찰 조작과 바로 이어짐 | ◎ 추천 |
| **심해 문어** (새) | 촉수 머리 + 망토 안쪽 눈 무늬, 하늘색 피부 | 청색·검정 + 주황 눈 | 망토 눈이 뜨고 촉수가 문틈·배수구로 | 물소리·배수구 | ◎ (슬라임과 "물" 겹침) |
| **올빼미 하피** (2차) | 눈가를 덮은 얼굴 깃털 + 숄처럼 두른 날개(R3), 밤에 깨어 낮엔 늘 졸림 | 베이지·흰색 + 노랑 눈 | **고개가 180도 돌아감**(concept 2단계 "목이 이상한 각도") · 숄이 펼쳐짐 · 목에서 깃털이 돋음(R8) | 밤에 깨어 있는 기숙생 = 순찰 중 마주침 | ◎ 추천 |
| **아귀** (2차) | 앞머리에서 늘어진 초롱 머리핀(R9), 웃으면 큰 이빨 | 회백·검정 + 청록 빛 | **복도 끝 손전등 같은 빛 = 그녀의 초롱**(가짜 빛으로 유인) | 손전등·빛 규칙과 반대로 이어짐 | ◎ 추천 |
| **후드 기생체** (새) | 동물 머리 모양 후드 레인코트 | 회청 + 노랑 | 후드가 본체, 사람 몸은 미끼 | 우비 = 비 오는 밤 | ○ (레퍼런스 06·07과 너무 가까움 주의) |

**추천 6명 (2차 반영):** 흡혈귀 · 슬라임 · 구미호 · **강시** · **올빼미 하피** · **아귀**
- 강시 = 수칙 종이, 올빼미 = 고개가 돌아가는 밤새, 아귀 = 가짜 빛. 세 명 모두 몸의 훅이 밤 순찰 장치(규칙·마주침·빛)와 바로 이어진다.
- 하피·깃털은 레퍼런스에서 가장 많이 고른 방향이라 한 자리 넣는다. 나방은 올빼미와 날개 실루엣이 겹쳐서 뺀다(후보로 남김).
- 피부: 사람 피부 3(흡혈귀·구미호·강시) + 사람 아님 3(슬라임 반투명·올빼미 깃털·아귀 회백) — R6.
- 색: 와인 / 민트 / 주홍 / 노랑 부적 / 베이지+노랑 / 청록 빛 — 겹치지 않음. 금 장신구(R10)는 6명 공통.
- 3D 부담: 아귀는 다리 있는 모습(인어 하반신 X), 올빼미는 사람 팔 + 날개 숄로 시작(날개 팔은 3D 시험 뒤).
