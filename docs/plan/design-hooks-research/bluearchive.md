## 2. 같은 학교인데 다르게 보이게 하는 패턴

1. **학교 공통 기호는 「하나」만 정하고 나머지는 풀어 준다.** 게헨나는 뿔·날개·꼬리 중 몇 개를 가졌는지가 학생마다 다름(이부키만 셋 다, 세리카는 꼬리 없는 고양이 귀). 트리니티는 날개, 아리우스는 헤일로의 십자, 붉은겨울은 톱니바퀴 헤일로(체리노·토모에·마리나·라나·모미지).
2. **같은 교복을 「무엇을 뺐나」로 구분.** 호시노는 블레이저를 뺌, 노노미는 넥타이·블레이저 둘 다 뺌, 세리카만 정석대로 입음. 아비도스 다섯 명이 거의 같은 옷인데 다 다르게 읽힘.
3. **겉옷을 「입지 않고 걸친」 자세로 성격 표시.** 카스미 = 실험복을 팔뚝에, 노아 = 재킷을 팔에, 코코나 = 재킷을 왼팔에만, 코노카 = 어깨에 얹음, 키쿄 = 하오리를 어깨에, 노노미 = 가디건 흘러내림.
4. **교복 위에 「다른 세계」의 겉옷 한 벌.** 네루 = 메이드복 + 스카잔, 카즈사 = 교복 + 후디(리본은 후디 위로), 카요코 = 「Born.To.Kill」 후디, 요시미 = 바시티 재킷, 라부 = 군용 헬멧.
5. **좌우 비대칭 하나.** 하나에 짝짝이 니삭스, 이즈나 한쪽 양말, 미치루 오른팔만 기모노 소매, 츠쿠요 스커트 왼쪽이 다 트임, 시로코 한 손만 장갑, 오토기 한쪽만 무릎 보호대.
6. **헤일로를 머리 장식으로 한 번 더.** 유우카 = 헤일로 닮은 삼각 머리끈, 우타하 = 헤일로의 사이버 날개로 머리 묶음, 나구사 = 헤일로도 머리 장식도 눈송이.
7. **헤일로에 직업·취미를 그림으로.** 후우카 주먹밥, 이즈미 햄버거, 하루나 「접시를 겨누는 조준경」, 유즈 전원 버튼, 레이 야구장, 우이 시계, 사야 원자, 코토네 물고기 꼬리, 치아키 카메라 렌즈.
8. **짝 캐릭터는 같은 틀 + 색 바꾸기 / 좌우 뒤집기.** 모모이·미도리(헤일로·헤드셋 같은 모양, 색만 바꿈, 총에 단 참 색도 서로 바꿈), 히카리·노조미(헤일로·송곳니 위치 거울상), 아리스·케이(헤일로 뒤집고 파랑 → 분홍).
9. **머리 「안쪽 색」·「끝 색」.** 카즈사 흑 + 안쪽 자홍, 치히로 흑 + 안쪽 베이지, 키쿄 흑 + 안쪽 회색, 츠쿠요 보라 + 안쪽 노랑, 미카 분홍 → 끝 하늘, 사오리 남 → 하늘, 카린 흑 → 끝 보라, 후우카 끝만 하늘색.
10. **머리 길이를 극단으로.** 아리스·츠루기·에리는 바닥까지(에리는 바닥에 고임), 유카리는 발을 넘어 무릎께에서 묶음, 반대로 마리나는 픽시 컷. 긴 머리를 「어디서 묶나」도 훅(유카리 무릎, 카요코 뿔).
11. **인외 부위에 「사연 한 군데」.** 에리카 꼬리 끝 하트가 깨진 흉터, 니야 한쪽 부러진 뿔 + 금 고리, 히나 뿔의 빛나는 금, 사츠키 루비 결정 뿔, 와카모 꼬리 끝 리본, 렌게 팔·발 불꽃 무늬.
12. **인외 부위에 「쓰임새」.** 스즈미 머리 옆 날개 = 자기 섬광탄 가리개, 카요코 뿔 = 머리 묶는 곳, 후우카 염소 뿔 = 잔머리 고정.
13. **가짜 인외 부위로 집단을 묶음.** RABBIT 소대는 토끼 귀를 헤드폰·헬멧·머리띠로(미야코·사키·미유), 모미지는 동물 귀 후드, 키라라는 뿔 머리띠.
14. **무기를 캐릭터 소품처럼 꾸밈.** 모모이·미도리 총구에 결정, 유즈 게임기 무늬 + 냥캣 화면, 모미지 곰 탄두 RPG, 레이사 별 무늬, 나츠 컵케이크 끈, 세리나 총검 자리에 주사기, 츠루기 피 묻음, 마키 그라피티.
15. **한 모티프를 3곳 이상 반복.** 아야네 나비(핀·양말·총), 우미카 파도(옷·헤일로·총), 레이사 하늘·분홍(머리·양말·총), 아이리 아이스크림(머리 장식·가방).

## 3. 동아리·소속이 옷에 드러나는 법

1. **동아리마다 「겉옷 한 장」.** 백화요란 = 하늘색 꽃무늬 하오리(나구사·유카리·키쿄·렌게), 티파티 = 케이프렛(나기사·미카·세이아), 구호기사단 = 간호모 + 의료 완장 + 바시티 재킷(하나에·세리나·미네), 만마전 = 군용 코트 + 군모(마코토·이로하·치아키·이부키).
2. **직업 소품이 곧 동아리.** 급양부 반다나·앞치마(후우카·쥬리), C&C 메이드복, 엔지니어부 고글·실험복(히비키·우타하), 출판부 뉴스보이 캡(야쿠모), 공무부 안전모(미노리), 발키리 확성기(키리노), 하이랜더 차장 모자(히카리).
3. **완장·글자·번호로 「소속 표시」를 따로 붙임.** 선도부 완장(이오리·치나츠, 히나는 망토 빈 소매에), 「Justice」 글자(하스미), C&C 코드 번호 「02」(카린)·「04」(토키), 아즈사 양 소매에 두 학교 문장.
4. **같은 동아리 = 같은 헤일로 틀.** 만마전 이부키·이로하(원 + 가시 4 + 마름모), 세미나 유우카·노아(기계식), 아리우스 십자, 붉은겨울 톱니. 틀은 같고 색·방향만 바꿈.
5. **같은 동아리 안에서는 「한 명만 다른 점」을 의도적으로.** 세리나만 구호기사단에서 검은 리본, 아즈사만 아리우스 시절 헤일로에 십자 없음, 세리카만 대책위원회에서 교복을 정석대로 입음. 「다른 한 점」이 그 학생의 이야기가 됨.
