## 1. 품질 목표 — 4단 비교
비교 그림(스팀 스크린샷 12장, 남의 그림이라 **저장소에 넣지 않고 채팅으로만** 보냄): A 저예산·스타일 / B 인디 실사풍 / **C 준AAA 인디** / D AAA.
| 단 | 예 | 특징 | 만드는 규모 |
|---|---|---|---|
| A | Mouthwashing · Fears to Fathom | 저폴리·강한 색, 또는 어둠으로 가림 | 1~2인 |
| B | Chilla's Art · MiSide · 화이트데이 리메이크 | 실사풍이지만 소품·재질 밀도가 낮음 | 1~5인 |
| **C** | **The Exit 8 · Platform 8 · Anemoiapolis · Road to Vostok(Godot)** | 좁은 공간을 **사진처럼**: 형광등·타일·광고판·반사. 공간이 작고 반복돼서 소규모로 가능 | 1~5인 |
| D | MADiSON · SILENT HILL 2 리메이크 · Layers of Fear(2023) | 고밀도 소품·실시간 GI·안개·후처리 전부 최고 | 수십 명 |
- **추천 목표 = C단.** 이유: ① 우리 무대(기숙사 복도·방)가 C단 게임들처럼 **좁고 반복되는 실내** ② The Exit 8·Platform 8은 우리 "순찰 + 이상현상"과 같은 장르 ③ Road to Vostok이 **Godot로 C단 실내**를 보여 줌 ④ D단은 팀 규모가 필요.
- 낮 분위기 참고 = MiSide(밝은 애니풍 실내) · 밤 = C단 + 화이트데이(한국 학교 밤).

## 2. 맵 괴현상 연출 — 종류와 만드는 법
| 괴현상 | 실제 예 | 만드는 법 (Godot) |
|---|---|---|
| **복도가 길어짐** | Layers of Fear(문 너머가 길게 늘어난 복도) | (a) 안 볼 때: 복도 모듈을 끼워 넣음 (b) 보는 중에 천천히: 끝 벽을 뒤로 밀면서 사이에 모듈 추가 + 화면 각도(FOV)를 조금씩 바꿔 "당겨지는" 느낌(돌리 줌) (c) 걸어도 가까워지지 않음: 끝 벽이 내 속도로 같이 멀어짐 |
| **끝없는 복도(반복)** | P.T.(문을 나가면 같은 복도), The Exit 8, Antichamber | 똑같은 구간 두 개를 두고 구간 끝에서 **보이지 않게 순간이동**. 조명·소품이 똑같아야 이음새가 안 보임 |
| **안 볼 때 바뀜** | Layers of Fear: 빛·소리로 시선을 끌고 등 뒤를 바꿈("뒤돌아보지 마"라고 하면 다들 돌아봄) | 카메라가 안 보는지 검사(화면 밖 감지 노드·각도) → 방·소품 교체 |
| **문 너머가 다른 곳 / 안이 더 큰 방** | Antichamber, P.T. | **포털**: 문에 다른 장소를 비추는 카메라 화면 + 넘으면 순간이동. Godot 애드온 Portals 3D(MIT, Godot 4.5+, 포털 속 포털은 안 됨) · simple-portal-system(MIT) |
| **문을 열면 벽** | Layers of Fear | 문 뒤 장면을 상태에 따라 바꿔 끼움 |
| **번호·표지판·소품이 틀림** | The Exit 8(이상한 점 찾기) | 같은 구간에 "변형 목록"을 켜고 끔 — 이상현상 데이터 표 |
| **조명이 바뀜** | P.T.(불 꺼짐 → 붉은빛) | 조명 세트 바꾸기 |
| **천장이 낮아짐·기울어짐** | — | 모양을 천천히 늘이기·기울이기(트윈), 소리와 함께 |
- **원칙(사례 공통):** 괴현상은 **언제 터질지 플레이어가 모르게**(P.T.의 "패턴 없음") · **시선을 끌어 놓고 다른 곳을 바꿈** · 테스트 플레이로 사람들의 습관을 보고 고침.
- **구조에 주는 영향 (중요):**
  1. 배경은 **바꿀 수 있는 모듈(조각)** 로 만든다 → 스캔·AI 월드(스플랫)는 모양을 바꿀 수 없어 **괴현상과 맞지 않음** → "AI가 돕는 일반 3D 제작"(M3)이 더 확실한 답.
  2. 미리 구운 조명(라이트맵)은 움직이지 않는 공간용 → 바뀌는 구간은 ① 모듈마다 조명을 따로 구워 같이 움직이거나 ② 그 구간만 실시간 조명 위주 ③ 두 상태를 각각 굽기. 어느 쪽이 되는지 **시험 필요 [확인 필요]**.
  3. 순간이동 반복은 조명이 같아야 하므로 "똑같은 구간"을 한 번 구워 복사해 쓰는 게 유리.

## 3. AI로 어디까지 되나 (2026-11 현재, 자료 근거)
| 단계 | AI가 해 주는 정도 | 사람이 할 몫 |
|---|---|---|
| 블록아웃(벽·복도·방 치수) | **잘함**. 공포 병원 맵 하루 제작 사례에서 블록아웃의 약 70%, 흩뿌리기 80%를 AI가 함. 반복·측정 작업(기둥 간격, 모듈 맞추기)은 거의 완벽 | 공간이 "좋게 느껴지는지" — 비율·불규칙함 |
| 공간 배치 정확도 | **약함**. 코딩 에이전트 3D 장면 벤치마크(Code4Scene, 2026-11): 모든 에이전트에서 "공간 구성"이 가장 낮은 항목. 장면을 고칠 때 34%는 원하지 않은 곳도 바꿈 | 치수·규칙을 문서로 주고, 정해진 카메라로 찍어 확인 → 고치기를 반복 |
| 소품 | **초안까지**. AI 3D로 만든 게임 13개 조사: 생성 그대로 쓴 것은 거의 없음 — 면이 너무 많고 그림자가 색에 칠해져 나옴 → 면 줄이기·재질 손질 필수. 책상·의자 같은 단순 소품은 AI가 Blender로 직접 만든 게 더 쓰기 좋았다는 보고 | 특징 소품 다듬기, 크기·밀도 맞추기 |
| 재질 | **잘함** — 사진 스캔 CC0 재질 + AI PBR 재질 생성 | 낡은 정도·색 통일 |
| 큰 맵 한 번에 | **안 됨**. "기술 보드처럼 보임" — 반복이 드러나고 밀도·위계가 부족. 구역 하나(복도 한 칸)를 먼저 완성해 규칙을 증명하고 넓히는 방식이 맞음 | 구역 계획·우선순위 |
| 조명·분위기 | **초기 배치까지**(빛 종류별 배치·값 설정). 같은 사례에서 조명은 사람이 60% | **마지막 20%** — 직접 걸어 다니며 어둠과 밝음의 경계 맞추기 |
| 이야기 소품 | 거의 못 함 — "의미 있는 위치"가 핵심 | 휠체어가 창을 향함, 멈춘 시계 같은 배치 |
| AI 월드 생성(스플랫) | 출시된 게임 사례 없음. 빛이 고정, 모양 변경 불가 | 참고·콘셉트용 |
- **한 줄:** AI는 "빠른 80%"를 만들고, **품질을 정하는 20%(조명·배치·이야기 소품)는 사람의 눈**이 필요하다. 사례 공통 흐름 = 규칙 정하기 → 만들기 → 찍기 → 보고 거르기 → 규칙 고치기.
- Claude가 직접 할 수 있는 것: 모듈 키트·블록아웃 스크립트, 괴현상 시스템 코드, 조명 초기 배치, 정해진 카메라로 찍어 비교하기. 사용자 몫: 참고 그림 고르기, 조명 최종 판단, 걸어 보고 "무서운지" 판단.

## 4. 결론 [후보]
- 품질 목표 = **C단**(The Exit 8·Platform 8·Road to Vostok 수준의 좁은 실사 실내).
- 엔진 = **Godot 유지 근거가 더 강해짐**: 괴현상은 모듈·포털·순간이동 코드가 핵심이고(Godot 애드온 있음, Claude가 코드로 다루기 쉬움), C단 실내는 Godot로 실례가 있음.
- 제작 = AI가 돕는 일반 3D(M3) + 사람이 조명.

## 5. 다음 — "고퀄 복도 한 칸" 시험에 괴현상 2개 포함 (PC)
1. C단 참고 그림 3장 고르기(위 비교 그림에서).
2. 복도 모듈 키트(6m 구간·방문·소품) → 낮/밤 조명 굽기.
3. 괴현상 2개: **① 안 볼 때 복도가 길어짐 ② 끝없는 반복 구간** — 구운 조명과 함께 이음새가 안 보이는지 확인.
4. 종이인형 카드 1장 세우기 → 참고 그림과 나란히 찍어 비교.

## 6. D단(AAA·고밀도)도 되나? (2026-11-27, 사용자 질문) [후보]
**한 줄:** 게임 전체를 D단으로는 어렵다. **좁은 공간 몇 곳만 D단에 가깝게**는 된다. 단, D단을 목표로 하면 엔진은 언리얼 쪽이 맞다.

**작은 팀이 D단에 가까이 간 실제 예**
| 게임 | 인원·기간 | 어떻게 |
|---|---|---|
| MADiSON | **2명, 약 5년**(Unity) | 감독이 그림·연출 전부 담당. 3ds Max·Substance Painter/Designer·ZBrush로 직접 제작. 집 한 채에 모든 구석까지 소품·이야기. 개발자 말: "Unity로 이런 무거운 그림을 내느라 수백 가지 문제를 풀었다" |
| The Exit 8 | **1명, 약 9개월**(UE5) | 개발자가 게임 회사 3D 배경·재질 전문가 출신(4~5년). 지하 통로 하나를 반복. 재질은 Substance로 직접, 사람은 MetaHuman·스캔 인물 에셋, 카메라 흔들림·후처리도 구매 에셋. "에셋은 쓸 수 있으면 쓴다" |
| SILENT HILL 2 리메이크 · Layers of Fear | 큰 스튜디오(UE5) | 실시간 GI·고밀도 소품·수많은 아티스트 |

**D단에 필요한 것 (우리에게 없는 것)**
1. **숙련된 3D 배경·재질 아티스트의 손** — MADiSON·The Exit 8 모두 핵심이 이것. AI는 지금 "빠른 80%"까지(§3).
2. **사진 같은 에셋 생태계** — 언리얼은 MetaHuman·스캔 에셋·실시간 GI(Lumen)가 바로 붙음. Godot는 이 생태계가 작고, 구석 그늘·계단 현상 줄이기 품질도 언리얼보다 낮음.
3. **시간** — 공간 한 곳을 D단으로 채우는 데 몇 달 단위.
