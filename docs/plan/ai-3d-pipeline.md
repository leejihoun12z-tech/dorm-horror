# AI로 서브컬처 게임급 3D 캐릭터 만들기 — 제작 방식 구상

_작성: 2026-11-20 · 상태: 전체 [후보] · 사용자 지시: "진짜 AI를 통해 서브컬처 게임급 모델링을 뽑을 방법을 구상해봐"_
_관련: `dorm-horror-plan.md` §7 (조사·시험 기록). 이 문서가 제작 방식의 기준이다._
_주의: 아래는 설계안이다. 실제 품질은 §7 관문 시험으로 확인하기 전까지 "예상"이다._

## 1. 결론

**"그림 넣으면 완성 모델이 나오는" 한 방 방식으로는 서브컬처급이 안 나온다.**
대신 서브컬처 게임 회사가 실제로 쓰는 구조를 그대로 가져오고, **사람 손이 가장 많이 드는 자리에만 AI를 넣는다.**

> **공용 명품 틀 1벌 + 캐릭터마다 AI 부품 + 공용 셰이더**
> (원신도 캐릭터 수십 명이 몸 틀 5종과 같은 셰이더, 같은 뼈대를 나눠 쓴다)

## 2. 서브컬처 캐릭터가 좋아 보이는 이유 7가지

| # | 요소 | AI 한 방 결과 | 이 방식의 해결 |
|---|---|---|---|
| 1 | **얼굴 모양**: 어느 각도에서도 그림처럼 보이게 일부러 다듬은 얼굴 | 울퉁불퉁, 각도마다 다른 얼굴 | 공용 마스터 얼굴을 쓴다 (AI가 만들지 않음) |
| 2 | **얼굴 그림자**: 빛 방향별로 미리 그려 둔 그림자 지도 | 없음 (지저분한 그림자) | 마스터 얼굴에 한 번만 만든다 → 전원 공유 |
| 3 | **평면 색 텍스처**: 빛·그림자가 안 그려진 깨끗한 색 | 원화의 그림자가 그대로 구워짐 | 원화를 평면 색으로 다시 그려서 3방향에서 입힌다 |
| 4 | **셰이더**: 2단 명암, 가장자리 빛, 머리카락 광택, 고른 외곽선 | 없음 | 공용 셰이더 1벌을 만든다 → 전원 공유 |
| 5 | **표정**: 얼굴 변형 수십 개 | 없음 | 마스터 얼굴에 들어 있다 → 전원 공유 |
| 6 | **흔들림**: 머리카락·치마·꼬리 물리 | 없음 (한 덩어리) | 부품별로 나눠 만들고 뼈 사슬을 스크립트로 심는다 |
| 7 | **동작**: 같은 뼈대로 만든 고품질 동작 | 뼈대가 매번 다름 | 공용 뼈대 1개 → 동작 모음 1벌을 전원이 쓴다 |

→ 7개 중 **5개(1 얼굴 모양·2 얼굴 그림자·4 셰이더·5 표정·7 동작)는 "한 번만 잘 만들면 모든 캐릭터가 물려받는" 것**이다. AI가 매번 만들 필요가 없다.
→ AI가 캐릭터마다 만들 것은 **머리카락, 옷, 장식, 인외 부위, 색 텍스처**다. 이것은 AI 3D가 비교적 잘하는 "덩어리 형태"다.

## 3. 3층 구조

### 1층. 공용 자산 (한 번만 만든다. 품질의 대부분이 여기서 나온다)
| 자산 | 내용 | 만드는 법 |
|---|---|---|
| 마스터 몸 + 얼굴 | 애니풍 얼굴(깨끗한 면 흐름), 표정 변형 50개 이상, 체형 조절 | §5 참고 (구매 또는 외주) |
| 공용 뼈대 | 사람형 표준 뼈대 + 머리카락·치마·꼬리용 사슬 규칙 | 마스터에 포함 + Claude 스크립트 |
| 공용 셰이더 (Godot) | 2단 명암 + 색 띠, 얼굴 그림자 지도, 외곽선(부드럽게 편 노멀), 가장자리 빛, 머리카락 광택 띠, 금속, 스타킹 | Claude가 작성. 참고: 공개된 원신풍 셰이더 분석 자료 |
| 동작 모음 | 대기, 걷기, 대화 몸짓, 놀람, 공포용 뒤틀린 동작 | Mixamo, Meshy 동작 생성, 영상→동작 AI |

### 2층. 캐릭터별 부품 (AI가 만든다)
```
① 틀 위에 덧그리기: Claude가 직접 그린 비율 안내선 그림(마스터 몸의 머리 크기·어깨·허리·다리 길이 표시) 위에 AI(GPT 이미지 등)가 캐릭터를 덧그린다
   ※ 구매한 베이스의 렌더 그림은 AI에 넣지 않는다 (판매 베이스의 "AI 입력 금지" 조건, `master-base-candidates.md` §4)
   → 원화의 비율이 마스터 몸과 정확히 맞는다 (던전 게임 몬스터 도트에서 쓴 "틀 위 덧그림"과 같은 원리)
② 부품 원화 분리: 머리카락만 / 옷만 / 장식만 / 인외 부위만 (평면 색, 그림자 없음)
③ AI 3D (Meshy·Tripo 여러 장 이미지→3D): 부품별로 따로 생성. 또는 통째로 만든 뒤 AI 부위 분리(Tripo 세그먼트: 머리카락·얼굴·팔 등 9~52개 부위로 나눔)
④ 얼굴 그림: 눈·눈썹·입·홍조 텍스처를 2D로 그린다 (캐릭터의 개성은 여기서 나온다)
```

### 3층. 자동 조립 (Claude가 Blender 스크립트로 한다)
| 단계 | 하는 일 |
|---|---|
| 정리 | 겹친 점 합치기, 폴리곤 줄이기(부품당 목표치), 크기·위치를 마스터에 맞춤 |
| 텍스처 다시 입히기 | AI가 구운 텍스처 대신 ②의 평면 색 원화를 3방향에서 입힌다. 안 보이는 곳은 AI 그림으로 채운다 |
| 명암 지도 만들기 | 주름 그늘(자동 계산) → 그림자 강도 지도, 재질 구분 지도(금속·천·피부) |
| 붙이기 | 옷은 몸의 뼈 영향값을 옮겨 받는다. 머리카락·치마·꼬리는 길이 방향으로 뼈 사슬을 자동 생성 |
| 외곽선 준비 | 부드럽게 편 노멀을 계산해 저장 (외곽선이 끊기지 않게) |
| 내보내기 | Godot로 가져와 셰이더·흔들림 설정 → 정해진 각도·조명으로 자동 촬영 → 검수 그림 |

## 3-1. 실제 서브컬처 게임에서 가져온 규칙 (2026-11-20, `subculture-model-research.md` §4)
- 노멀맵은 쓰지 않는다. AI 3D가 구운 명암·노멀맵은 버리고 평면 색만 쓴다.
- 그림자 색은 따로 그리지 않고 기본 색에서 변환 표(피부·옷·머리카락)로 만든다.
- 그림자 마스크: 자동 초안(주름 그늘 계산) → 규칙 보정 → 사용자 검수. 가장 손이 가는 단계다.
- 눈은 홍채·흰자·하이라이트 3층으로 그린다. 하이라이트는 따로 움직인다.
- 표정 보조 덧그림: 홍조, 창백, 눈물, 식은땀, 만화 눈.
- 손전등 같은 점광원은 노멀을 무시하고 거리·범위만 적용한다. 얼굴 명암은 툰 규칙을 유지한다.
- 목표 수치 [작업값]: 폴리곤 4만~6만(머리카락 약 40%), 뼈 150~300, 텍스처 8~15장(2K), 표정 변형 100개 이상.

## 4. 단계별 도구와 위험

| 단계 | 도구 | Claude가 직접? | 위험 | 대책 |
|---|---|---|---|---|
| 원화 (틀 위 덧그림) | GPT 이미지, Meshy 이미지 API | 가능 (API) / GPT는 사용자 또는 크롬 | 앞·옆·뒤 그림이 서로 다름 | 한 장에 3면을 같이 그리게 한다, 검수 코드로 판정 |
| 부품 3D | Meshy 7.1, Tripo | 가능 (API, 유료 키) | **머리카락 품질** (가장 큰 위험) | 앞머리·옆머리·뒷머리를 따로 생성, 안 되면 머리카락만 반수동 |
| 부위 분리 | Tripo 세그먼트 | API 확인 필요 | 경계가 지저분함 | 처음부터 부품별 생성을 기본으로 한다 |
| 정리·붙이기 | Blender (명령어) | 가능 (bpy 5.3이 설치 목록에 있음, 실행은 관문 1에서 확인) | 옷이 몸을 뚫음 | 옷 안쪽 몸은 지운다 (게임 표준 방식) |
| 셰이더 | Godot 4.7 | 가능 | Godot에 원신급 기성 셰이더가 없음 | 직접 작성 (얼굴 그림자 지도는 마스터 1개만 만들면 됨) |
| 표정·입 모양 | 마스터 얼굴 내장 | — | 마스터 품질에 전부 달림 | §5에서 신중히 고른다 |
| 동작 | Mixamo, Meshy 동작, 영상→동작 AI | 일부 가능 | 동작이 딱딱함 | 대화 몸짓 위주 소수 정예, 공포 동작은 뼈 직접 조작 |

## 5. 마스터 얼굴·몸을 어디서 얻나 (가장 중요한 결정)

> **2026-11-20 대체:** 사용자 "얼굴을 바꾸면 퀄도 낮아지고 다 비슷해진다" → 얼굴은 교체하지 않고 **AI 얼굴을 그대로 살리는 방법**으로 간다(`ai-face-keep-plan.md`). 아래 마스터는 얼굴 교체용이 아니라 **면 구조 틀과 표정 변형의 원본**으로만 쓴다.

얼굴이 품질의 대부분이다. AI 3D는 애니 얼굴을 못 만든다. 그래서 **1벌만 좋은 것을 구한다.**

| 안 | 내용 | 비용 (추정) | 품질 | 메모 |
|---|---|---|---|---|
| A. 판매 베이스 구매 (추천: 시작용) | 애니풍 베이스 메쉬 (표정 변형 90개 이상 포함 상품이 있음) | 수만~십수만 원 | 중상~상 | **게임 상업 이용이 명시된 라이선스만.** 상품마다 다르므로 구매 전 약관 확인 |
| B. 전문가 외주 1회 | 우리 그림체에 맞춘 얼굴·몸·표정 | 수십~수백만 원 | 상 | 캐릭터 1명이 아니라 "틀 1벌" 값이라 효율이 높다 |
| C. AI + 스크립트로 자체 제작 | AI 머리를 다듬어 틀로 만듦 | 낮음 | 불확실 | 얼굴 면 흐름과 표정을 자동으로 만들기 어렵다. 비추천 |

- VRoid는 주력에서 뺐다(사용자 결정). 다만 A를 고르는 동안 **뼈대·조립 스크립트 시험용 임시 틀**로는 쓸 수 있다(화면에 보이는 최종 품질과 무관).
- 추천 순서: **A로 시작 → 관문 2에서 얼굴이 아쉬우면 B**.

## 6. 인외 기숙생 처리
| 종류 | 방법 |
|---|---|
| 귀·뿔·꼬리·날개 (구미호, 악마, 하피) | AI 부품 생성 → 머리·엉덩이 뼈에 붙이고 뼈 사슬 추가 |
| 하반신이 다른 종족 (라미아, 아라크네) | 상반신 = 마스터, 하반신 = AI 3D 부품. 뱀 꼬리는 긴 뼈 사슬, 거미 다리는 다리별 뼈 |
| 슬라임 | 마스터 몸 + 반투명·굴절 셰이더 + 흘러내리는 AI 부품 |
| 기계 (안드로이드, 인형) | 관절 이음새를 텍스처와 부품으로 표현 |

## 7. 관문 시험 (작게 확인하고 넘어간다)
| 관문 | 만드는 것 | 통과 기준 | 실패하면 |
|---|---|---|---|
| 1 | AI 부품 1세트: 머리카락 + 옷 (기숙생 1명분) | 정지 화면에서 머리카락과 옷이 "덩어리 찰흙"처럼 보이지 않음 | 머리카락 생성 방식을 바꾸거나 머리카락만 반수동으로 |
| 2 | 마스터 + 부품 조립 + 공용 셰이더 → Godot 정지 화면 | 사용자가 "서브컬처 게임 느낌 난다"고 판정 | 마스터 교체(B안) 또는 셰이더 보강 |
| 3 | 표정 + 흔들림 + 걷기 동작 영상 | 움직일 때 깨지지 않음 | 뼈 사슬·영향값 규칙 수정 |
| 4 | 인외 1명 (꼬리 또는 하반신) | 관문 2·3과 같은 기준 | 종족 목록 조정 |

- 관문마다 결과 그림을 사용자에게 보내고, 통과해야 다음으로 간다.

## 8. 예상 품질 (솔직하게)
- **정지 화면·중간 거리: 서브컬처 게임 느낌에 가깝게 갈 수 있다고 본다.** 그 느낌의 큰 부분이 셰이더·얼굴 그림자·평면 색인데, 이것은 한 번 만든 공용 자산에서 나온다.
- **얼굴 클로즈업: 마스터 얼굴의 품질 그대로다.** AI와 무관하다.
- **가장 불확실한 것: 머리카락.** 애니 머리카락은 다발 모양이 생명인데 AI는 뭉개는 경향이 있다.
- **원신·명조와 같은 급은 아니다.** 그쪽은 캐릭터당 전문가 여러 명이 몇 달을 쓴다. 목표는 "1인 인디에서 보기 드문 급"이다.
- 이 문단은 조사와 설계에 근거한 예상이다. 관문 1·2를 지나야 확인된다.

## 9. 비용 추정 [작업값]

|---|---|

## 10. 정할 것
1. 이 방식(공용 틀 + AI 부품 + 공용 셰이더)으로 갈지
2. 마스터: A 구매로 시작 (추천) / B 외주 / 직접 고른 상품
3. AI 3D: Meshy로 시작 (추천, Claude가 API로 직접 돌림) / Tripo
4. 관문 1을 바로 시작할지 (Meshy 유료 + API 키 필요)
