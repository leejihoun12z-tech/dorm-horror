## 1. 「무섭게 생김」이 아니라 「기괴함」을 만드는 규칙
| # | 규칙 | 뜻 | 예 |
|---|---|---|---|
| G1 | **익숙한 것이 조금 틀림** | 처음부터 괴물 얼굴이 아니라, 아는 얼굴·몸에서 하나가 틀림 | 웃는 시간이 1초 길다 · 손가락 마디 하나 더 |
| G2 | **그 아이의 표지를 끝까지 남김** | 괴물이 돼도 리본·머리핀·옷 조각 하나로 「그 애」인 걸 알아봄 | 5단계 괴물 몸에 걸린 분홍 카디건 조각 |
| G3 | **사람 부분이 틀린 곳에** | 얼굴·손·입이 있어야 할 곳이 아닌 데 있음 | 볼 실밥이 입이 됨 · 머리카락 사이 손 |
| G4 | **너무 많거나 너무 적음** | 개수가 틀림 | 눈 여럿 · 관절 하나 더 · 얼굴이 없음 |
| G5 | **비율이 천천히 늘어남** | 단계마다 팔·목·손가락이 조금씩 길어짐 | 손가락 1.1 → 1.3 → 2배 |
| G6 | **움직임·자세가 틀림** | 생김새보다 자세가 더 무서움 | 목이 뒤로 돎 · 네발 · 등이 뒤로 꺾인 다리 |
| G7 | **재질이 바뀜** | 피부가 다른 것이 됨(피 대신) | 썩은 살 · 뿌리 · 도자기 · 그림자 |
| G8 | **귀여운 디테일은 그대로** | 리본·꽃·소품이 그대로라서 더 섬뜩 | 괴물이 그대로 든 구급상자·꽃다발 |
| G9 | **피·내장 없음** | 수위 기준 그대로 | 상처 대신 실밥·금·빈 속 |

## 2. 단계 사다리 (사용자 11-27 — 좀비 예시)
> 정정(사용자 11-27): 이 표는 **강도의 예시**이지 모든 캐릭터에 같은 부위를 적용하는 틀이 아님. 단계 = 강도, 무엇이 바뀌는지는 캐릭터마다 다름 → `night-mutation-cast-20261127.md` §0·§3.
| 단계 | 사용자 말 | 얼굴 | 몸·자세 | 인외 속성 | 얼굴 강도 |
|---|---|---|---|---|---|
| 낮 | — | 디자인대로 | 디자인대로 | 디자인대로 | 0 |
| **1** | 평범한 상태 · 평범한 피부 · 인외 속성만 살짝 | 사람 얼굴, 하이라이트 없는 눈 | 사람 피부색, 그대로 | 한 군데만 살짝(실밥 하나·꽃 하나) | 1 |
| **2** | 역안 · 무섭고 기괴한 표정 · 조금 이상한 움직임 | **역안**(흰자 검게·홍채 밝게) · 너무 긴 웃음 · 고정된 시선 | 고개를 이상하게 기울임 | 피부색이 돌아오기 시작 | 2~3 |
| **3** | 얼굴이 새까맣고 눈만 보임 · 이상하게 꺾임 · 목이 돌아감 | **얼굴 전체가 검은 구멍, 흰 눈 둘만** | 목이 뒤로 돌아감 · 어깨 높이가 다름 · 팔이 너무 김 | 크게 드러남 | 3 |
| **4** | 사실적인 이빨 / 새까만 입속 · 반쯤 괴물 | 검은 얼굴 + **찢어져 열린 큰 입, 새까만 입속, 들쭉날쭉한 이빨** | 네발로 기기 · 관절 하나 더 · 긴 손톱 | 몸 반이 종족 특징으로 | 예외 [사용자 11-27] |
| **5** | 기괴한 공포 얼굴 + 완전 괴물 | 얼굴이 갈라진 입·여러 눈 | **실루엣까지 다른 괴물** · 뒤로 꺾인 몸 · 부러진 듯 긴 팔다리 | 종족 그 자체 · **그 아이의 표지 1개는 남김** | 예외 [사용자 11-27] |

## 4. 만드는 법
| 단계 | 방법 | 시험 결과 (좀비, 11-27) |
|---|---|---|
| 1·2 | 낮 그림을 밑그림으로 다시 그림, 강도 0.45~0.55 (구도·옷 그대로) | ✓ 잘 됨 |
| 3 | 강도 0.65는 낮 자세에 묶여 목이 안 돎 → 0.82로 올려 자세를 바꿈 | ✓ NZ3b_2 (NZ3b_1은 피 튄 자국이라 뺌) |
| 4 | 0.75는 「무서운 표정의 소녀」에 그침 → 3단계 그림을 밑그림으로 0.9 + 네발·긴 팔 · 옷(블라우스·긴 치마)을 글로 분명히 | ✓ NZ4c_1 (2차는 블라우스가 빠짐) · 얼굴은 검게 안 남음 |
| 5 | 밑그림을 쓰면 괴물이 안 됨 → 밑그림 없이 새로 그리고 표지(카디건·꽃 머리핀·긴 회색 치마)를 글로 남김 | ✓ NZ5c_1 — 뒤로 꺾인 몸·거꾸로 매달린 머리·뿌리 다리 (2차는 교복 치마가 끼어듦) |
