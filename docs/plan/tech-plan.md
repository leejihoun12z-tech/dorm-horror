## 1. 추천 한 장
> **Godot 4.7로, 3D 기숙사를 1인칭으로 걸어 다닌다. 캐릭터는 먼저 2D 그림(입간판)으로 3D 공간에 세우고, 3D 모델은 시험을 통과한 캐릭터부터 바꿔 끼운다. 대화는 미연시처럼 그림 + 표정 + 대사창. 사감실 업무는 책상 위 서류 화면.**

- 이유 1: 지금 아트가 만들고 있는 것이 2D 그림(ComfyUI)이다. 이 그림으로 **바로 게임을 만들기 시작할 수 있다.**
- 이유 2: "캐릭터는 AI 3D"(사용자 [확정])는 버리지 않는다. 다만 AI 3D 품질은 아직 검증 전이다(관문 1 미통과). 3D를 기다리느라 게임 전체가 멈추지 않게 **순서만 뒤로** 둔다.
- 이유 3: 같은 방식의 선례가 있다. **단간론파** 시리즈는 3D 학교를 1인칭으로 돌아다니고, 캐릭터는 2D 그림으로 서 있다.

### D2. 캐릭터를 화면에 어떻게 보여 줄까 (가장 큰 결정)
| 안 | 내용 | 작업량 | 위험 |
|---|---|---|---|
| A. 전부 3D | 메인·조연·엑스트라 모두 AI 3D 모델 | 가장 큼 (27명 + 엑스트라) | AI 3D 품질이 기대에 못 미치면 게임 전체가 멈춤 |
| **B. 2D로 시작 → 3D로 바꿔 끼우기** (추천) | 처음엔 모두 2D 입간판. 캐릭터를 보여 주는 부분을 **교체 가능하게** 만들어 두고, 3D 관문을 통과한 캐릭터부터(메인 우선) 3D로 바꿈 | 작게 시작, 점점 늘림 | 끝까지 2D로 남는 캐릭터가 생길 수 있음 (조연·엑스트라는 2D로 남아도 됨) |
| C. 끝까지 2D | 3D 공간 + 2D 캐릭터로 확정 | 가장 작음 | "3D 캐릭터" 목표를 포기 |

| **D. 낮 로우폴리 + 대화 2D + 밤 괴물 AI 3D** (사용자 제안 2026-11-25, 추천) | 평소엔 단순한 로우폴리 3D 캐릭터가 돌아다님 → 말을 걸면 2D 일러스트 + 표정으로 대화 → 괴물화(변이 3~4단계)는 AI 3D 고밀도 모델. AI 3D의 어색함·기괴함이 오히려 장점이 됨 | 중간 | 로우폴리와 일러스트 차이가 커 보일 수 있음 → 아래 맞추는 법 |

**D안을 배경과 어울리게 맞추는 법 [후보]**
1. 2D 일러스트는 **대화 화면(UI 층)**에만 나온다. 3D 공간 안에 세우지 않는다 → "초상화"로 읽혀서 어색하지 않다(페르소나·단간론파 방식).
2. 로우폴리 캐릭터와 배경은 **같은 밀도·같은 셰이더·같은 외곽선·같은 팔레트**로 만든다. 차이는 "배경 대 캐릭터"가 아니라 "3D 세계 대 대화 초상화"로만 생기게.
3. 로우폴리 모델은 일러스트의 **실루엣·머리색·인외 훅(가장 큰 특징)**만 정확히 따라 한다. 세부는 버린다.
4. 대화가 열릴 때 배경을 살짝 어둡게·흐리게 하고 초상화를 밀어 넣는다.
5. 밤 괴물 모델은 낮 모델보다 **더 생생하고 촘촘하다** — "밤에만 너무 진짜 같다"는 어긋남 자체를 공포로 쓴다. 어둠·손전등·셰이더로 배경과 이어 붙인다.
6. 변이 1~2단계는 로우폴리 모델에 작은 변형(눈·그림자·목 각도·멈춤), 3~4단계에서 괴물 모델로 바뀐다. **바뀌는 순간은 플레이어가 안 보고 있을 때.**
- 로우폴리는 리깅이 깨끗하게 되고(면이 단순함), 멀리서 보니 얼굴 표정이 필요 없다(눈·입 그림 바꾸기면 충분) → 앞 §5-1의 "고치기·리깅·표정" 걱정 대부분이 줄어든다.
- 로우폴리 정도(PS1풍 거친 것 / 깔끔한 툰 저폴리)와 몸 비율은 시안 그림으로 정한다.

- **2D 입간판도 공포가 된다:** 옆에서 보면 종이처럼 얇다 · 내가 돌아도 그림은 정면만 본다 · 밤에는 그림이 "조금씩 다른 장"으로 바뀌어 있다. 불쾌한 골짜기(아트 바이블 §2-1)와 잘 맞는다.
- 3D 모델은 움직임(고개 돌리기·멈춤·흉내)의 공포가 더 강하다. 그래서 **메인 6명은 3D가 목표**로 남는다.

## 3. 정해지면 만드는 구조 (추천 설계)
| 부분 | 하는 일 | 1인 개발 포인트 |
|---|---|---|
| **하루 진행기** | 아침 → 낮 → 저녁 → 점호 → 순찰 → 새벽을 순서대로 진행. 시간대마다 열리는 장소·할 일을 바꿈 | 하루 흐름을 코드가 아니라 데이터 표로 |
| **데이터 파일** | 기숙생 명부(방·일과·종족의 "정상"), 이상현상, 수칙·쪽지, 업무(택배·외박 명단 만드는 규칙), 대사 | 내용 추가 = 표에 한 줄 추가 |
| **이상현상 4가지 표현** | ① 공간 부품 바꾸기(문·전등·소화기) ② 사람 바꾸기(그림 장·위치·인원) ③ 소리 ④ 글자 바꾸기(수칙·명부·송장) | 이상현상 하나 = "언제·어디서·무엇을·정답 대응" 한 줄 |
| **저장 두 겹** | 하루 상태(회귀하면 전날 아침으로 되돌림) + 남는 지식(일지·도감·알아낸 규칙) | 회귀 장치가 저장 구조에서 바로 나옴 |
| **캐릭터 보여 주기 층** | 2D 입간판 / 3D 모델을 같은 방식으로 다룸 → 캐릭터마다 바꿔 끼움 | D2-B가 가능해지는 핵심 |
| **3D 기숙사** | 1m 격자 모듈 부품(벽·문·창·계단·가구) + 툰 셰이더(아트 시안 A를 이어 씀) | 층·방이 많아도 부품 조립 |
| **대화** | 직접 만든 간단한 대화 장치 또는 Godot용 대화 추가 기능(Dialogic 2) [확인 필요: Godot 4.7에서 안정적인지 첫 시험에서 확인] | 대사는 표 파일로 |

## 4. 첫 시험판 (수직 단면) [작업값]
`dorm-horror-plan.md` §8을 새 하루 흐름에 맞춰 바꾼 것.

| 항목 | 범위 |
|---|---|
| 공간 | 1층 사감실·현관 + 1개 층(복도·방 4·세탁실) |
| 기숙생 | 2명 (2D 입간판) + 엑스트라 3~4명 |
| 기간 | 3일 (회귀 포함) |
| 아침 업무 | 외박 명단 대조 · 택배 정리 (2가지) |
| 낮 | 수리·민원 1건 + 대화 1번 |
| 밤 | 점호 → 순찰(체크리스트 5항목), 이상현상 6개, 배드엔딩 1개 → 전날로 회귀 |

**만드는 순서**
1. **회색 상자 판**: 그림 없이 상자·글자로 하루 흐름 전체가 돌아가게 (재미의 뼈대 확인)
2. **그림 넣기**: 아트의 2D 그림 + 툰 배경 + 소리
3. **사용자 플레이** → 고칠 것 정리 → 3D 캐릭터 관문 결과를 보고 D2 다음 단계

**확인 목표**
1. 아침 업무가 지루하지 않고, 그 안의 "이상한 한 줄"이 소름 돋는지
2. 점호·순찰이 무서운지
3. 2D 입간판 캐릭터가 3D 공간에서 어색하지 않은지 (어색함이 공포로 쓰이는지)

## 5. 위험과 대책
| 위험 | 대책 |
|---|---|
| 기숙생이 많아 대사·그림 양이 폭발 | 시험판 2명 → 데모 메인 2~3명 → 정식. 조연·엑스트라는 대사 한두 줄 |
| 2D 입간판이 싸구려로 보임 | 툰 배경과 같은 외곽선·명암으로 맞춤, 발밑 그림자, 그림 해상도 높게. 첫 시험에서 바로 찍어서 판정 |
| 3D 관문이 계속 실패 | D2-B라 게임은 멈추지 않음. 메인도 2D로 남기는 C로 넘어갈 수 있음 |
| 1인칭 3D 멀미·조작 피로 | 시야각·흔들림 설정, 이동 속도 조절, 업무는 책상 화면으로 |

## 5-1. 3D 캐릭터 — 고치기·리깅·모션이 되나 (2026-11-25 조사, 사용자 질문)
사용자 기준 = Tripo 스튜디오 프로필의 모델 수준(링크는 이 세션 네트워크에서 막혀 직접 못 봄). 질문: "사소한 문제·디테일 수정, 자연스러운 모션·리깅이 가능한가."

| 할 일 | 가능? | 방법 | 누가 |
|---|---|---|---|
| 겹친 점·구멍·크기·재질 나누기·폴리곤 수 | 됨 | Blender 스크립트 | Claude |
| 부위별 다시 뽑기(손·머리카락·소품) | 대체로 됨 | Tripo 부위 나누기(segmentation) → 그 부위만 다시 생성·교체 | Claude/사용자(웹) |
| 관절이 잘 접히는 면 구조 | 됨 | Tripo 쿼드 리토폴로지(재배치) → 그다음 리깅 | 웹 기능 |
| 손가락·얼굴 비율 같은 세밀한 모양 | **어려움** | 사람이 직접 깎기, 또는 여러 번 다시 뽑아 고르기. Claude는 눈으로 깎는 작업을 잘 못 함 | 사용자/외주 |
| 텍스처 정리 | 대체로 됨 | 툰 셰이더라 평면 색으로 정리(스크립트) + 웹 텍스처 편집 | Claude |
| 몸 리깅 | 됨 | Tripo·Meshy 자동 리깅(사람형·크리처) | 웹 기능 |
| 머리카락·치마·꼬리 흔들림 | 됨(손이 감) | 흔들림 뼈 추가(Blender 스크립트) + Godot 흔들림 뼈 기능 | Claude |
| 얼굴 표정 | **자동 안 됨** | 대화는 2D 표정(D5-A), 3D는 눈·입 그림 바꿔 끼우기 | Claude |
| 걷기·대기 같은 기본 동작 | 됨 | 기성 사람형 동작을 옮겨 씀 | Claude |
| 캐릭터 고유 동작(꼬리·인외 몸짓) | 손이 감 | 직접 키 애니메이션 또는 영상→모션 AI | Claude/사용자 |
| 공포 동작(멈춤·고개 돌림·어긋난 타이밍·흉내) | **쉬움** | 코드로 만듦 | Claude |

**결론 [후보]:** 정지 화면은 Tripo 수준이 나온다. 진짜 일은 **움직였을 때 안 깨지게 만드는 것**이다. 메인 4~6명은 1인 개발로 가능한 범위, 27명 전부 3D는 무리. 판정은 아래 시험 하나로 한다.

**시험 (캐릭터 1명, 끝까지 한 줄로)**
1. 아트 그림 1장 → Tripo 생성 → 부위 나누기·쿼드 리토폴 → 자동 리깅
2. Blender 정리 스크립트 → Godot 복도에 세움(툰 셰이더) → 대기·걷기·고개 돌리기·멈춤 + 머리카락 흔들림

## 5-2. 배경 품질을 어디에 맞추나 (2026-11-25, 사용자 질문) [후보]
사용자 걱정: "배경을 로우폴리에 맞추면 품질이 낮아 보이고, 밤 공포가 줄 것 같다."

- **품질은 면 수가 아니라 빛·재질·후처리·소리에서 나온다.** 아트 채팅의 배경 시안 A·B·C는 셋 다 **같은 단순한 상자 부품**이다. 그런데 B(반실사) 밤은 가장 무섭고, A(툰) 밤은 가장 덜 무섭다 → 걱정하신 그대로이고, 원인은 면 수가 아니라 밤의 빛과 후처리다.
- **추천: 부품(모양)은 하나, 낮과 밤은 "보이는 방식"만 바꾼다.**
  - 모양: 배경·캐릭터 모두 같은 밀도의 로우~미드폴리 모듈
  - 낮: 툰(A) — 따뜻한 파스텔·외곽선. 일러스트·로우폴리 캐릭터와 잘 맞음
  - 밤: 추천 1 = 어둡고 부드러운 빛·안개(B 밤) / 추천 2 = 거친 저해상도·점 무늬(C 밤). 날이 갈수록 밤 후처리를 더 거칠게(변이 단계와 함께)
  - Godot는 빛·후처리를 실행 중에 바꿀 수 있어서 같은 장면 하나로 된다
- **밤 괴물 AI 3D 모델**은 밤 빛·안개·후처리 아래에서만 보이므로 배경과 어긋남이 가려지고, 오히려 "밤에만 진짜 같다"가 된다(§D2-D 5번).
- 비교 그림: `assets/art_wip/dorm_daynight_mix_20261125/daynight_mix.jpg` (아트 시안 그림을 낮·밤으로 다시 짝지음. 실제 게임 화면 아님, 상자 대역)

## 5-4. "Family Time 느낌" 캐릭터 — 스크린샷 분석 (2026-11-25, 사용자 제공 2장, 그림은 git 제외) [후보]
| 요소 | 그 게임에서 보이는 것 | 우리가 만드는 법 | 난이도 |
|---|---|---|---|
| 모양 | 면이 적은 로우폴리. 팔·어깨에 각진 면이 보임. 머리카락은 큰 덩어리 몇 개 + 끝이 들쭉날쭉 | 공용 데포르메 몸 + 머리카락 덩어리 부품 (Blender 또는 AI 3D 로우폴리 출력 후 정리) | 낮음 |
| 얼굴 | **그린 얼굴(텍스처)**: 큰 눈 테두리·속눈썹·작은 눈동자·송곳니 미소가 선으로 그려짐. 입체 눈알·표정 뼈 없음 | 우리 2D 일러스트(ComfyUI)에서 눈·입을 그려 텍스처로 씀 → **표정 = 얼굴 그림 바꾸기**. AI 얼굴을 살리는 계획(`ai-face-keep-plan.md`)과 그대로 맞음 | 낮음 |
| 칠 | 거의 평면 색 + 아주 옅은 그림자 1단. 옷의 무늬·털 끝 지그재그를 **텍스처에 선으로 그려 넣음**(셰이더 외곽선 아님) | 그려 넣은 텍스처 + 옅은 툰 셰이더 1~2단. **밤 손전등이 먹도록 빛을 받는 셰이더로** (빛을 안 받는 평면 칠이면 밤 공포 연출이 안 됨) | 낮음 |
| 색 | 캐릭터마다 2~3색으로 아주 좁음(검정·흰 피부 / 갈색 계열) → 멀리서도 실루엣이 읽힘 | 아트 바이블 규칙 "2~3색 + 강조 1색"과 같음 | — |
| 비율 | 엄마 약 6.5등신(어른 몸), 아이들 약 2등신 | 우리 데포르메 5~6등신 [작업값 5.5] 그대로. 엑스트라 중 일부를 더 작게 할 수 있음 | — |
| 배경 | 로우폴리 나무 + 붓 터치 텍스처, 옅은 하늘 | 우리 낮 툰 배경에 그린 텍스처를 섞으면 같은 결 | 중간 |
| 공포 결 | 텅 빈 듯한 큰 눈 + 송곳니 미소 = 귀여운데 살짝 섬뜩 | 변이 1~2단계를 **얼굴 그림 바꾸기**로 싸게 표현(눈 하이라이트 꺼짐·미소 조금 넓어짐, 강도 상한 3 안에서) | 낮음 |

- **가져오는 것은 "만드는 법"(로우폴리 + 그린 얼굴 + 그려 넣은 선 + 좁은 색)뿐이다.** 캐릭터 생김새·무늬·눈 모양은 그 게임 것을 따라 하지 않는다. 우리 기숙생 디자인(아트 채팅 명단)을 이 방법으로 만든다.
- 이 방법이면 앞의 걱정(세밀한 수정·표정·리깅)이 대부분 사라진다: 면이 적어 리깅이 깨끗하고, 표정은 그림 바꾸기이고, 세부는 텍스처에 그린다.
- 다음 시험: 우리 기숙생 1명을 이 방법으로 → 낮 복도·밤 손전등 정지 화면 + 표정 3개 + 걷기 10초.
