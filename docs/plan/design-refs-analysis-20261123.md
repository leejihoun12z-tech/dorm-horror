# 참고 그림 20장 분석 + 특이한 생물·크리처 후보 (2026-11-23)

사용자: 「이것들 더 분석해보고 바로 그리진 마 · 좀 더 독특하고 특이하고 임팩트 있으면서 매력적인 디자인 · 두루미·까마귀 같은 흔한 애들 말고 특이한 생김새 동물·크리처 · 좀비·슬라임도 키워드 하나를 더해서」.
참고 그림은 채팅으로만 받았고 git에 넣지 않음, AI 생성에 붙이지 않음. 아래는 **방법**만 정리한 것이고, 어느 그림의 캐릭터·옷·문양도 그대로 따라 그리지 않는다.

## 2. 공통 원칙 (지금 규칙 18가지에 더할 것) [후보]

| 기호 | 원칙 | 예 |
|---|---|---|
| R1 | **컨셉을 옷의 모양으로**: 무늬를 찍지 말고 옷 형태가 컨셉 | 행성 고리 모자 · 지느러미 망토 · 생물 머리 후드 |
| R2 | **인외 부위 = 머리 모양·장식**: 경단머리가 눈알, 머리카락이 촉수·불 | 눈알 경단 · 촉수 양갈래 |
| R3 | **색은 2색 + 점 하나**: 무채색 몸 + 보색 한 쌍, 또는 두 색 + 작은 강조 | 청록·주황 / 흑백 + 주황 한 점 |
| R4 | **피부를 재료·무늬로**: 사람 피부색 대신 그 생물의 무늬·질감 | 범고래 흑백 · 은빛 반짝이 · 파란고리 |
| R5 | **머리 위 큰 실루엣**: 뿔·더듬이·고리·원판·모자 중 하나는 크게 | 원판 머리 장식 · 거대한 뿔 |
| R6 | **얼굴에 하나 더**: 셋째 눈 · 그림자 얼굴 · 색 있는 혀 · 반짝이 동공 | 이마 눈 · 초록 혀 |
| R7 | **실제 특이한 종을 고르고 그 종의 무늬를 그대로** | 파란고리문어 · 범고래 · 망치상어 |
| R8 | **컨셉 + 한 단어**: 흔한 괴물에 반대·의외 키워드 하나 | 범고래+불 · 미라+짐승 신 · 미라+보물 · 로리타+눈알 |
| R9 | **큰 소품이 곧 능력**: 소품 하나로 무엇을 하는 애인지 | 거대한 붓 · 닻 |
| R10 | **동반 생물** 하나 | 따라다니는 상어 · 붕대 머리 |
| R11 | **눈 모티브를 장식에 숨김**(공포 미연시에 특히 맞음) | 망토 눈무늬 · 꽃 속 눈 · 보닛 눈알 |
| R12 | **설정화엔 변신 전후·키·성격 메모를 같이** | 꼬마 그림·가면 쓴 그림 |

## 3. 우리 규칙과 부딪히는 곳 [확인 필요]

참고 그림 대부분은 **판타지 의상**(판초·로리타·무녀 장식·이집트 금장)이다. 지금 우리 규칙은 「평범한 대학생 사복, 교복 금지」.
- 안 A (추천): **낮 = 사복 바탕 + R1·R2로 컨셉을 옷 모양에 녹임**(예: 행성 고리 같은 챙 모자, 지느러미처럼 끝이 갈라진 롱 카디건). **밤 = 판타지 쪽으로 크게 변이**(원판 장식·보닛 눈알 같은 것은 밤 그림에서).
- 안 B: 사복 규칙을 풀고 처음부터 판타지 의상.
- 안 C: 사복 그대로, 소품·색·피부만 바꿈(지금 방식에 가까워 덜 튐).

| 새 개념 | **사이렌 + 노래방** | 노래로 홀리는 실용음악과 | 마이크 · 깃털 · 비늘 |

## 6. 다음

### 7-2. 53장 합친 결론
- 사용자가 고른 그림은 **흑백·회색 바탕 + 강조 한 색**, **어두운 피부 + 흰 머리**, **숨은 입·숨은 눈**, **몸이 곧 옷(후드·망토·지느러미)**, **설정화(꼬마·변신 전후·메모)** 쪽이 많다.
- 다만 한 방식으로 다 만들면 다시 비슷해진다 → **방식(공식)을 7가지로 나누고 캐릭터마다 다르게 배정**한다.

### 7-4. 29명 배정안 [후보] (확정 5명 제외 · 바꿀 생물은 §4)
| 방식 | 기숙생 | 한 줄 |
|---|---|---|
| T1 생물 무늬 (3) | 문어 → 파란고리문어 · 비단잉어 · 두루미 → 넓적부리황새 | 파란 고리 무늬 피부 / 흰 바탕·검정·빨강 잉어 점 세 색 / 회청색 깃·나막신 부리 마스크 |

| T4 큰 실루엣 (4) | 세라핌 · TV 머리 · 가스 헬멧 · 노란 옷 연극부 | 얼굴 앞 금빛 후광 관(13번 방식) / 리본 안테나 / 유리 헬멧 연기 / 큰 망토 칼라 + 가면 |

- 한 캐릭터에 방식은 **하나가 주, 많아야 하나가 보조**. 같은 방이나 같은 학과끼리는 같은 방식을 피한다.
- 옷도 한 가지로 묶지 않는다: 사복 그대로 / 사복 + 모양(R1) / 판타지 쪽을 섞는다 — §3 결정과 같이 정한다.
