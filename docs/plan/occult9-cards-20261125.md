## 2. 카드별 자세히

### 1. 팔척귀신 — 「키 큰 모델학과 선배」
- **옷**: 바닥까지 끌리는 흰 롱 셔츠 원피스 · 챙 넓은 흰 모자(리본에 부적 여러 장) · 목에 옛 트랜지스터 라디오(남의 목소리가 나오는 곳).
- **구도**: 상반신이지만 문틀 위에 머리가 닿아 고개를 숙인 모습 → 키가 그림 한 장에서 보이게.
- **공포 단계**: 낮 = 다정한 키 큰 선배, 모자를 절대 안 벗음 → 밤 = 2층 창밖에 모자 챙이 보이고 라디오에서 「포포포」 잡음 → 정체 = 아는 사람 목소리로 창문을 열어 달라고 함.
- **수칙**: 창밖에서 아는 목소리가 불러도 창문을 열지 말 것.

### 2. 축시 참배 — 「저주 대행 공방 언니」
- **옷**: 흰 기모노풍 셔츠 · 못 주머니 달린 목공 앞치마 · 짚인형 키링 여러 개 · 나무망치 · 통굽 나막신 부츠.
- **공포 단계**: 낮 = 소원 들어주는 짚인형 키링을 나눠 줌 → 밤 = 새벽 2시 뒷산에서 못 박는 소리, 촛불 왕관 → 정체 = 내가 받은 키링에 누군가의 이름표.
- **수칙**: 새벽 2시 뒷산에서 못 박는 소리가 나면 보러 가지 말 것.
- 물건 후보 「제웅」을 여기 합침.

### 3. 빨간 마스크 — 「미용과 에이스」
- **옷**: 벨트 맨 베이지 트렌치코트(안감에 꿰맨 자국 무늬) · 허리 홀스터에 미용 가위 여러 자루 · 등에 큰 가위 · 붉은 하이힐 · 지퍼가 웃는 입처럼 그려진 흰 마스크.
- **공포 단계**: 낮 = 무료로 머리 잘라 주는 미용과 → 밤 = 「나 예뻐?」 → 정체 = 마스크를 내리면 귀까지 찢어진 입.
- **수칙**: 예쁘냐고 물으면 「보통이에요」라고 답할 것.
- ⚠ 포투쏙독새(밤에 찢어지는 입)와 겹침 → 둘 중 하나 [사용자 결정].

### 4. 화장실 셋째 칸 — 「3층 화장실 청소 근로」
- **옷**: 흰 블라우스 · 빨간 멜빵 치마 · 빨간 망토(안감 파랑) · 노란 고무장갑 · 「3」 칸 번호 머리핀.
- **나이**: 원전은 아이 귀신 → 30년 전 기숙생(성인)으로.
- **공포 단계**: 낮 = 늘 3층 화장실만 청소하는 수줍은 언니 → 밤 = 셋째 칸 안에서 대답 → 정체 = 「빨간 휴지 줄까, 파란 휴지 줄까?」
- **수칙**: 셋째 칸은 세 번 두드리지 말 것 · 빨강·파랑을 물으면 답하지 말 것.

### 5. 저승사자 — 「학생회 출석 담당」
- **옷**: 은방울 달린 검은 갓 · 롱코트처럼 재단한 검은 도포(소매·자락이 연기로 흩어짐) · 출석 태블릿(명부) · 붉은 갓끈 구슬.
- **공포 단계**: 낮 = 결석자를 귀신같이 아는 점호 도우미 → 밤 = 명부에 없는 이름을 부름 → 정체 = 세 번째에 대답한 사람이 사라짐.
- **수칙**: 이름을 세 번 부르면 대답하지 말 것.
- 계약 악마(검정·빨강·흰)와 색이 겹치지 않게 빨강은 갓끈 구슬만, 바탕은 검정·은·청록.

### 6. 우물 원혼 — 「늘 젖어 있는 식당 알바」
- **옷**: 젖은 흰 리넨 원피스 · 조리실 앞치마 · 등 뒤 깨진 청화 백자 접시 아홉 장이 후광처럼 떠 있음(열 번째 자리 빔) · 두레박 줄.
- **공포 단계**: 낮 = 식당에서 접시를 세는 조용한 알바 → 밤 = 우물 쪽에서 「한 장… 아홉 장」 → 정체 = 「하나 모자라」 하며 돌아봄.
- **수칙**: 접시 세는 소리가 아홉에서 멈추면 열을 세지 말 것.
- 사다코의 원조인 옛 전설(오키쿠)이라 저작권 걱정 없음. 「젖은 긴 머리」는 이 한 명만.

### 7. 일본 유령 — 「휴학 중(영원히)인 선배」
- **옷**: 오버사이즈 흰 수의를 후드 기모노처럼 · 손을 숨긴 긴 소매 · 삼각 두건을 머리띠 리본처럼.
- **공포 단계**: 낮 = 공용 거실 소파에서 늘 졸고 있는 선배 → 밤 = 혼불이 복도를 떠다니고 다리가 없음 → 정체 = 졸업 앨범 옛 사진에만 있는 사람.
- **수칙**: 혼불이 따라오면 불을 끄지 말 것.
- 처녀귀신과 둘 중 이것(삼각 두건 실루엣이 더 잘 알아봄). 뺀 지박령 자리를 대신.

### 8. 갓파 — 「수영장 지킴이」
- **옷**: 래시가드 · 수영부 저지 · 호루라기 · 오이 스틱 · 접시에 연꽃과 작은 금붕어.
- **공포 단계**: 낮 = 인사성 바른 수영장 지킴이 → 밤 = 공용 욕조에 몇 시간이고 잠겨 있음, 발목을 잡음 → 정체 = 접시 물이 마르면 성격이 사납게 바뀜.
- **수칙**: 샤워실에서 인사를 받으면 꼭 고개 숙여 인사할 것(접시 물이 쏟아지면 힘을 잃음).

### 9. 선로 귀신 — 「철도 동아리 차장」
- **옷**: 금단추 남색 차장 재킷 · 차장 모자 · 완장 · 회중시계 · 승차권 펀치.
- **공포 단계**: 낮 = 담요 덮고 휠체어로 다니는 철도 동아리 → 밤 = 복도 끝에서 탁탁 팔로 기는 소리 → 정체 = 담요 아래엔 녹슨 바퀴와 레일.
- **수칙**: 밤 복도에서 뒤에서 탁탁 소리가 나도 뛰지 말 것.
- 수위 규칙(피·고어 거의 없음) → 잘린 자리는 기계·증기로.
