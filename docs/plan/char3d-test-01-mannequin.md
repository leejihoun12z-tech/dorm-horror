## 2. 확인한 것 / 못 한 것
- 확인(정지 화면, 리눅스 Godot 4.7.1): 낮·밤 화면, 얼굴 4단계, 3단계 부품 이동, **눈을 돌렸다 돌아오면 머리 각도가 바뀜**(자세 변화 1회 기록).
- 고친 결함: 이목구비가 작음 · 앞머리가 모자챙처럼 두꺼움 · 브릿지 조각이 눈 위에 뜸 · 옆머리 빨간 끝이 귀마개처럼 보임.
- 못 한 것: 사람이 직접 걸으며 보는 무서움·귀여움 판단, 움직임(걷기), 실제 모델 품질.

## 3. 이 대역이 알려 준 것
- **마네킹은 부품 = 관절이라 리깅이 깨질 일이 없다.** 실제 모델도 부품별로 만들어 관절 하나씩에 붙이면 된다(피부처럼 늘어나는 변형이 필요 없음).
- **얼굴 그림 바꾸기만으로 0~3단계가 읽힌다.** 3D 표정이 필요 없다.
- 밤 손전등 아래에서 흰 플라스틱이 가장 먼저 보인다 → 마네킹은 "어둠 속 흰 형체"가 강점.

## 6. 실제 부품 1차 (2026-11-26, Blender 스크립트 = §5 A안)
| 부품 | 붙는 관절 | 내용 |
|---|---|---|
| 가발 | head | 정수리 + 옆·뒤 껍데기(정면 열림, 끝 들쭉날쭉) + 앞머리(눈썹 위에서 끝, 들쭉날쭉) · 빨간 브릿지(보는 사람 오른쪽 앞) · 안쪽 빨강(왼쪽 아래) |
| 베레모 | head | 빨강 + 얇은 검정 띠 · 보는 사람 왼쪽 앞에 검정 리본 + 금 장식 · 블록아웃과 같은 기울기 |
| 셔츠 | chest | 가슴 부드럽게 · 등 쪽 옅은 그늘 · 깃 두 장 |
| 리본 | neck | 줄무늬(검정·빨강) 날개 + 꼬리 · 금 테 빨간 보석 |
| 치마 | hips | 광택 검정 하이웨이스트 펜슬 · 금 단추 2×3 |
| 트렌치 | chest | 어깨에 걸침 · 앞 열림 · 바깥 검정/안 빨강 · 두께 · 빈 소매 2 · 왼쪽 소매 금 십자 · 견장 금 단추 |

- 만드는 법: `blender -b --python tools/char/build_mannequin_parts.py` → `assets/characters/mannequin/mannequin_parts.glb` (부품 6개, 면 약 1,000개). 물체 이름 `<관절>__<부품>`, 색 = 면마다 칠한 정점 색, 광택 = 재질 이름(hair·gloss·cloth·metal).
- Godot: `mannequin.gd`가 glb가 있으면 부품을 관절 밑에 붙이고 그 자리의 블록아웃 도형은 안 만듦(`use_model_parts = false`면 예전 모습). 셰이더 `char_toon`에 정점 색 옵션 추가.
- 확인(PC Godot 4.7.2, 정지 화면만): 낮 전신·3/4·얼굴 0~3단계·밤 손전등 — 오류 0, 안 볼 때 자세 바뀜 그대로. 다듬은 것: 어깨·빈 소매가 너무 넓음 → 좁힘, 베레모 검정 띠가 모자챙처럼 두꺼움 → 얇게. 전후 그림 `img/mannequin_parts_20261126/before_after.jpg`.
- 3단계(머리 거꾸로)에서는 가발도 같이 뒤집혀 입 쪽을 가린다 — 부품이 관절에 붙은 구조 그대로의 결과. 무서운지·고칠지는 사용자 판단.
- 남은 것: 얼굴 표정 그림(아트 채팅, ComfyUI) · 몸 부품 다듬기(관절 구·팔다리) · 손(립스틱) · 걷기·멈춤 동작. **사람이 직접 보며 판단 전.**
