## 원칙 (시험에서 배운 것)
0. **그림 기준 = 로우폴리 툰 렌더(W2)** [작업값, 사용자 11-26]: 면은 각지게 · 색은 평평하게(그림자 1단) · 장식은 빼지 말고 크게. 부위마다 단순한 정도를 다르게 하지 않는다(섞이면 불쾌한 골짜기).
1. **AI가 만든 모양·색을 Claude가 다시 손대지 않는다.** 자르기·면 1만까지 줄이기·색 다시 입히기·서로 다른 모델 섞기는 전부 품질을 깎았다.
2. **고칠 건 앞 단계(그림)에서 고친다.** 3D에서 고치면 훨씬 비싸고 덜 깨끗하다.
3. **단계마다 앞 단계와 나란히 놓은 그림으로 확인한 뒤 다음으로.** 확대(Tripo 화면·`rigged_shots.gd`)로 본다.
4. 합격 기준 = 게임 화면 1.2m(말 걸기 직전)·2.5m. 더 가까이는 대화용 2D 일러스트.

## 부분만 고칠 때
- Tripo 「편집」 매직 브러시(5크레딧): 자동 조작으로는 브러시가 안 켜짐 → **사용자가 직접** 문질러 칠하고 미리보기 생성.
- 찢긴 부위·열린 면: Tripo 「파트 보완」(부분별 생성 모델에서만, 차감 없었음).
- 모양 다듬기(구멍·조각된 눈 매끈하게 등): Blender 스크립트(`tools/char/sculpt_face_smooth.py` 방식, 렌더로 확인).

## 아직 안 정해진 것 (다음 시험 순서)
1. **표정 단계**: 얼굴이 텍스처에 그려져 있음 → 얼굴 자리만 다른 텍스처로 바꿔 끼우기(`RiggedCharacter.set_texture`) 시험.
2. **통일감**: 두 번째 캐릭터를 같은 시트 틀·같은 설정으로 뽑아 나란히. 안 맞으면 몸 1벌 기준 + 머리카락 없는 머리·머리카락·옷 따로(Charakuru·@LidaMidorin 방식).
3. **흔들림**: 코트·머리카락에 뼈 추가(Blender) + Godot 흔들림 뼈.
4. 여러 명일 때 속도: 20명까지 60fps(주사율 상한) — 낮은 사양 미확인.

## 쓰지 않는 것 [폐기·대체]
부분별 생성 + 색 따로 입히기(`prep_tripo_mannequin.py`·`merge_inner_pass.py`·`split_tripo_textured.py` 계열) · 관절마다 딱딱한 부품 붙이기(마네킹 블록아웃) · 껍데기 외곽선 · 뚜렷한 툰 그림자. 파일은 기록용으로 남김.
