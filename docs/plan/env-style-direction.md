- **이 사례들이 바꾼 판단:** "방 하나·복도 하나"는 AI가 사실적인 수준까지 간다(숙련자가 감독할 때). 어려운 것은 **게임 전체에서 같은 품질을 유지하는 것**과 **사람의 눈으로 판단하는 것**.
- **공통 방법(우리 규칙으로 채택 추천):** ① 참고 그림 1장 ② 카메라 고정 ③ 큰 것 → 작은 것 순서, 단계마다 멈추고 확인 ④ 단순 소품은 Blender 스크립트, 복잡한 소품은 Tripo → 정리 ⑤ 조명은 마지막에 참고 그림에 맞춤 ⑥ 스크린샷 → 비평 → 한 가지씩 고침.

## 3. 추천: ② 데포르메 형태 + 사실 조명 — "인형의 집 기숙사" [후보]
**한 줄:** 모양은 살짝 과장·단순(두꺼운 벽, 둥근 모서리, 약간 큰 문손잡이·스위치, 비율이 조금 이상한 복도), 재질과 빛은 진짜처럼(라이트맵 간접광·면 조명 형광등·안개·피사계 심도). 실제 미니어처를 찍은 듯한 화면.
- **왜:**
  1. **AI 한계와 맞음** — AI 3D의 약점(자잘한 결함·지저분한 면)이 단순·과장된 모양에선 덜 보이고, 품질을 정하는 조명은 엔진 설정·스크립트로 숫자로 맞출 수 있음.
  2. **종이인형과 한 세계** — 종이 주민 + 인형의 집 = "종이인형극 무대"가 게임 전체 콘셉트가 됨. 사실풍 배경에 종이 카드를 세울 때의 어색함이 없음.
  3. **공포에 유리** — Little Nightmares 제작진: "익숙하지만 낯선 인형의 집", 과장된 비율이 아이 눈에 비친 세상처럼 불안. 복도가 길어지는 괴현상도 이 세계에선 자연스러움.
  4. **8번 출구류(사실풍 이상현상 게임)가 넘치는 시장에서 첫인상이 다름.**
  5. 데포르메는 오래 가도 낡아 보이지 않음(사실풍은 기술 기준이 계속 올라감).
- **위험:** 너무 귀여워지면 공포가 약해짐 → 밤에는 같은 인형의 집이 어둡고 거칠어지는 규칙(기존 "낮 툰 / 밤 거칠게"와 같은 방향).
- **낮/밤:** 낮 = 따뜻한 형광등·창빛, 미니어처 느낌 강하게(얕은 피사계 심도) · 밤 = 손전등·안개·피사계 심도 끔, 모양 비율이 조금씩 틀어짐.

## 6. 홍보에서 눈길을 끄는 비주얼은? (2026-11-27, 사용자 질문) [후보]
**자료가 말하는 것**
- **Mouse: P.I. For Hire** — 크리에이터 2,460명·영상 1.26만 개·출시 30일 조회 7,290만. 핵심 = "1930년대 고무호스 만화가 3D 1인칭 슈터 안에" — **매체가 섞이는 낯섦**이 첫 1초에 읽힘.
- **MiSide** — "귀여운 애니 여친 → 공포" 반전 + 스트리머 반응 클립(마크플라이어 VOD 300만). 첫 달 120만~220만 장 추정.
- **Mouthwashing** — 마케팅은 트레일러 하나. 저폴리라도 **상징 이미지 하나**(붕대 감은 선장)와 스트리머 반응으로 첫 주의 10~15배 판매. 제작진: "귀여움과 기괴함 사이 얇은 선".
- 공통: 화면 스타일은 **썸네일·첫 1초**를 담당하고, 퍼지는 건 **"헉" 하는 순간 클립**과 스트리머 반응.

**우리 후보별 바이럴 힘**
| | 첫 1초에 읽히는 것 | 클립 | 약점 |
|---|---|---|---|
| ① 극사실 | "진짜 같은 복도에 애니 종이인형?!" — **대비가 가장 셈** | 사실 공포 + 납작한 인형 | 8번 출구류 사실풍 이상현상 게임이 넘쳐 배경만으론 묻힘 |
| ② 데포르메 | "귀여운 인형의 집" — 예쁜 썸네일 | 아늑함 → 공포 반전 | 첫인상이 순해 보여 "공포 게임"으로 덜 읽힐 수 있음 |
| ③ 단순 | 흔한 PS1풍 | — | 가장 묻힘 |

**추천: ②와 ①을 섞어 "변화"를 홍보 장면으로 — "인형의 집이 밤마다 진짜가 된다"**
- 낮 = ② 인형의 집(깨끗한 재질·따뜻한 빛·미니어처 흐림, 썸네일·애니 팬 유입).
- 밤 = 같은 모양에서 **재질·빛·화면이 사실풍으로 바뀜**(때·얼룩·습기, 흐림 끔, 필름 입자). **종이인형만 그대로 종이** → 밤에 오히려 이질감이 커짐.
- 바이럴 장면 = **낮 → 밤으로 바뀌는 5초**(같은 복도, 같은 인형, 세상만 진짜가 됨). "귀여움 → 공포" 반전(MiSide)과 "매체가 섞이는 낯섦"(Mouse P.I.)을 한 장면에.
- 만들기: 모양(데포르메 조각)은 한 벌, **재질 2벌 + 조명 2벌 + 후처리 2벌** — 가능 범위. 지금 시험 도구에 "밤 사실풍" 재질 세트를 더하면 시안을 바로 볼 수 있음.
- 상징 이미지 후보(Mouthwashing식 "그 장면"): 복도 끝에 선 종이인형이 손전등에 비치면 **그림자만 사람 모양이 아님**(§5-5-2 보류 아이디어 재사용).

## 9. 같은 배경에서 낮(데포르메)과 밤(극사실)을 섞을 수 있나? (2026-11-27, 사용자 질문) [후보]
**된다.** 모양(메시)은 하나로 두고, **겉(재질)·빛·화면 처리**만 두 벌로 만들어 바꾼다. §6 "인형의 집이 밤마다 진짜가 된다"를 게임에서 만드는 방법이다.
- 시안(2D 근사): `img/kv_mock_20261127/same_place_day_night.jpg`(같은 사진의 낮 미니어처 ↔ 밤 사실) · `locker_day_to_night.mp4`·`room_day_to_night.mp4`(형광등 깜빡임 → 꺼짐 → 진짜 밤, 각 4.6초). 배경 Poly Haven CC0 + 우리 일러스트.
- 게임에서 바꾸는 것 (모양은 그대로):

| 층 | 낮 = 인형의 집 | 밤 = 진짜 | 바꾸는 법 |
|---|---|---|---|
| 모양 | 데포르메(두툼한 벽·둥근 모서리·큰 손잡이) | **같음** | — (괴현상 때만 바뀜) |
| 재질 | 깨끗한 단색·큰 무늬·살짝 플라스틱 광택 | 스캔 재질: 얼룩·때·긁힘·습기 | 셰이더 값 하나(0→1)로 두 재질 섞기. 데칼(얼룩)도 같은 값으로 나타남 |
| 빛 | 형광등 면 조명·따뜻한 창빛 | 손전등·비상구 초록 불·가로등 | 빛 묶음 두 벌 켜고 끄기 + 라이트맵 두 벌 [확인 필요: 메모리] |
| 화면 | 얕은 피사계 심도(미니어처)·따뜻한 색 | 심도 끔·색 빼기·필름 입자 | 화면 효과(Environment·카메라 속성) 값 섞기 |
| 종이인형 | 종이 | **그대로 종이** | 안 바꿈 — 세상만 진짜가 되고 인형만 남는 게 핵심 |

- 섞는 방식 4가지 (같이 써도 됨):
  1. **한 번에 바뀜** — 점호 뒤 형광등이 깜빡이다 꺼지면 밤 세트로 (시안 영상 방식). 가장 간단, 홍보 5초 장면.
  2. **번져 감** — 한 지점(사감실 문·특정 방)에서 "진짜"가 물들듯 퍼짐. 셰이더에 거리 값만 더하면 됨.
  3. **손전등 속만 진짜** — 밤에 손전등이 비추는 곳만 극사실, 나머지는 어두운 장난감. 비춰야 보이는 공포(§5-5-2 시그니처와 이어짐, 보류 중).
  4. **날마다 조금씩** — 1일차 밤은 10%만 진짜, 마지막 주엔 낮에도 얼룩이 남음. 회귀·진행에 맞춘 긴 변화.
- 추천 [후보]: 기본 = 1(한 번에) + 4(날마다 조금씩). 2·3은 괴현상·연출 때 특별히.
- 비용: 재질을 두 벌 만들어야 함(데포르메용 깨끗한 판은 스캔 재질에서 색만 단순화해 자동으로 만들 수 있음, env-production-plan 2단계). 모양 키트는 한 벌.
- 한계: 이 시안은 사진을 2D로 처리한 근사다. 진짜 3D에서 같은 결과는 PC 채팅의 복도 한 칸 A/B 시험(env-production-plan §5-1)에서 확인해야 한다. 정지 화면·영상 관찰만, 사람이 보기 전.
