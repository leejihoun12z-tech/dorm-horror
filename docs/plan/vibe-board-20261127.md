## 2. 2.5D 이질감 — 종이 카드가 3D 세계에서 이상하게 구는 순간
1. **종이 비침** — 손전등을 카드 뒤에서 비추면 뒷면 그림이 비쳐 보임(뒷면 = 진짜 모습). 시안 ⑤.
2. **원근 무시** — 멀어져도 카드 크기가 그대로(또는 가까워질수록 작아짐).
3. **그림자만 다름** — 카드는 웃는데 바닥 그림자는 다른 모양. (§5-5-2 시그니처와 겹침, 보류 중)
4. **눈만 따라옴** — 옆으로 돌아 종이가 얇아져도 눈은 나를 봄.
5. **포스터·게시판 속으로** — 카드가 벽 포스터에 납작 붙어 들어가고, 다른 포스터에서 나옴.
6. **바닥에 눕기·접히기** — 쓰러질 때 종이처럼 접혀 바닥에 붙음.
7. **할핀 관절** — 평소엔 한 장인데, 이상할 때만 관절이 생겨 머리·팔이 따로 꺾임. 시안 ⑥.
8. **거울 속에선 3D** — 거울에 비친 모습만 입체(또는 그 반대).
9. **역전** — 밤엔 세상이 종이(납작한 배경화)가 되고 인물만 입체가 됨.

## 4. 독특한 시스템 — 한 줄로 설명되는 것
1. **틀린 수칙 찾기** — 매일 수칙 문서가 몰래 바뀜. 어느 줄이 가짜인지 (나폴리탄 수칙 + The Exit 8).
2. **점호 명부 대조** — 명부·사진과 실제 기숙생을 비교해 "없는 학생" 찾기 (That's not my Neighbor · No, I'm not a Human).
3. **손전등 비춤 = 종이 뒷면 보기** — 비춰야만 진짜가 보임 (§2-1, Sorry We're Closed의 제3의 눈 같은 역할).
4. **폴라로이드** — 찍으면 사진에는 일러스트가 아닌 "진짜"가 찍힘 (Viewfinder · 영 프레임).
5. **일지 쓰기가 다음 날을 바꿈** — 일지에 적은 대로 세계가 바뀜(거짓말을 쓰면?).
6. **낙서 봉인** — 이상한 것 위에 내가 직접 낙서해 덮음 (2D 공포 연출을 플레이어가 쓰는 쪽).
7. **회귀 기억** — 회귀할수록 기숙생 일부가 기억함 → 대화가 바뀜.
