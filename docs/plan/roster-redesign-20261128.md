## 1. 참고 그림에서 뽑은 장치 8개
| # | 장치 | 참고 그림에서 | 우리 게임에 쓰는 법 |
|---|---|---|---|
| P1 | **두 겹 실루엣 — 소녀 뒤의 괴물** | 소녀는 그대로, 등 뒤에 거대한 손·날개·짐승·촉수 입이 서 있음 | 밤 단계가 오를수록 **등 뒤의 것이 커짐**. 얼굴은 덜 망가져도 무서움 (얼굴 강도 상한과 잘 맞음) |
| P2 | **물건 머리·물건 몸** | 건널목 차단기, 천을 뒤집어쓴 머리, 물고기 무늬 천 귀신, 광대 | 물건 하나가 정체 = 한눈에 읽힘 (메모리 「물건 기반」과 같음) |
| P3 | **검은 구멍** | 얼굴·몸 일부가 새까맣게 비고 흰 눈·흰 이빨만 | 「없어야 할 곳이 비어 있음」 — 단계마다 넓어짐 |
| P4 | **몸의 입** | 가슴·몸통이 통째로 입, 금 간 얼굴 사이 입 | 입술 없이 삼각 이빨 + 진홍 안쪽 (11-25 규칙 그대로) |
| P5 | **개수 과잉** | 날개 깃마다 눈, 손가락 여러 개 | 한 곳에 몰아서 많이 (전신에 흩뿌리지 않음) |
| P6 | **극단 비율** | 키의 절반이 다리, 바닥까지 끌리는 팔·머리카락 | 길어지는 부위를 캐릭터마다 다르게 |
| P7 | **가린 얼굴 + 웃는 입** | 가면·손으로 눈을 가리고 입만 웃음 | 눈을 못 보는 게 더 불안함 |
| P8 | **색 = 흰·회색 + 강조색 하나** | 흰 머리·회색 옷 + 빨간 눈 / 파랑 / 분홍 | **밤 모습에만** 씀 — 낮 디자인까지 다 흰 머리면 명단이 겹침 |

## 3. 확인할 것 [확인 필요]
- **사이렌헤드**: 다른 작가가 만든 캐릭터라 이름·생김새를 쓰지 않음 → 「확성기 머리」로 바꿈. 기숙사 안내 방송 = 「방송이 틀린 수칙을 말함」이라 우리 수칙 공포와 바로 이어짐.
- **긴 캐릭터 4명**(팔척·뱀·사슴·확성기 머리): 길어지는 곳을 나눔 = 키 / 몸통 / 다리 / 기둥. 그래도 팔척 ↔ 확성기 머리는 둘 다 「위로 큼」 → 확성기 머리는 스피커·전선 쪽으로 몰기 추천.
- **목소리 2명**(장산범·확성기 머리): 장산범 = 문 밖 1:1 / 확성기 = 기숙사 전체 방송으로 나눔.
- **입 캐릭터 5명**(빨간 마스크·아귀·고블린상어·뒤통수 입·뱀): 더 줄이면 고블린상어부터.
- **흰 머리 몰림**: 참고 그림 대부분이 흰·회색 머리 → 낮 디자인은 캐릭터마다 다른 바탕색, 흰·회색 + 강조색은 밤 단계에서만.
- 해파리·문어·우비 합치기는 앞 문서(`night-mutation-cast-20261127.md` §4) 결정 대기 그대로.
