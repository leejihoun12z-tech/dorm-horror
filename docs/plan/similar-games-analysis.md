# 비슷한 게임 분석 — 미소녀 + 공포 장르의 성공·실패

_작성: 2026-11-20 · 사용자 지시: "비슷한 컨셉·게임성인 게임, 너무 똑같은 것, 미소녀 공포류 반응, 성공작·실패작 분석" · 상태: 조사 기록_
_대상 기획: `dorm-horror-concept.md` (낮 미소녀 ↔ 밤 변이, 인외 기숙사, 규칙 괴담, 회귀)_

**숫자 읽는 법:** "리뷰 수"는 스팀 검색 화면의 **영어 리뷰 수**다(전체 언어 합계는 더 많다. 예: MiSide 영어 2.6만 / 전체 14만). 판매량은 공식 발표가 있는 것만 "공식", 나머지는 "추정".

---

## 1. 결론
1. **똑같은 게임은 없다.** "인외 기숙생 여러 명이 밤마다 변하고, 규칙과 회귀로 버티는 3D 미연시"는 찾지 못했다. 다만 **부분적으로 겹치는 강한 게임이 4개** 있다(§2).
2. **장르 반응은 좋다. 하지만 "따라 한 게임"은 거의 다 묻혔다.** MiSide 이후 비슷한 3D 미소녀 공포가 많이 나왔지만, 영어 리뷰 1,000개를 넘긴 건 거의 없다(§4).
3. **성공작의 공통점은 "귀여움 + 반전"이 아니라 "마음이 가는 캐릭터 + 진짜 게임 구조 + 영상으로 퍼지는 순간"**이다(§5).

## 2. 겹치는 게임 (너무 비슷한지 판단)
| 게임 | 겹치는 점 | 다른 점 | 반응 | 위험도 |
|---|---|---|---|---|
| **MiSide** (2024-12) | 3D·1인칭·애니 미소녀가 공포로 바뀜 | 한 명(미타)이 주인공에게 집착. 기숙사·규칙·여러 명 없음 | 영어 리뷰 2.6만, 96%. 전체 14만 이상. 추정 88만 장 | **높음** — 같은 "3D 귀여운 소녀 공포"로 묶여 비교됨 |
| **Slay the Princess** (2023) | 회귀할 때마다 같은 소녀가 **다른 괴물 모습**으로 변함 | 2D 그림·글 중심, 한 명, 연애 시뮬 아님 | 영어 리뷰 2.5만, 96% | **중간** — "회귀 + 변이" 구조가 닮음 |
| **Doki Doki Literature Club** (2017) | 귀여운 연애 시뮬이 공포로 반전, 여러 소녀 | 2D 비주얼노벨, 메타(게임 파일) 공포 | 영어 리뷰 13만, 96%. 무료판 약 1,300만 다운로드(보도), 유료 Plus판 100만 장 이상(공식) | 낮음 — 장르의 원조라 비교는 받지만 구조가 다름 |
| **Monster Prom** (2018) | 몬스터 소녀·소년과 학교 연애 | 공포 아님(코미디) | 영어 리뷰 9천, 95% | 낮음 |

| Night Patrol Rules (2025) | **규칙 괴담 + 밤 순찰** | 캠퍼스, 무료 팬게임, 2.5D | 영어 리뷰 261, 99% | 낮음 |
| The Rules Kaidan: Night Watch | 규칙 괴담 + 밤 경비 | 출시 전(2027 1분기 예정) | — | **주시 필요** |

**판단:** 컨셉 전체가 겹치는 게임은 없다. 하지만 **보이는 첫인상(3D 귀여운 소녀가 무서워짐)은 MiSide와 바로 비교된다.** 그래서 홍보 첫 장면에서 **"여러 명 + 기숙사 + 규칙 + 종족마다 다른 변이"**가 함께 보여야 한다.

## 3. 장르 반응 (스팀 태그 묶음 조사)
| 묶음 | 게임 수 | 영어 리뷰 1,000개 이상 | 영어 리뷰 10개 미만 |
|---|---|---|---|
| 공포 + 연애 시뮬 + 애니 | 165 | 32개 (19%) | 25개 (15%) |
| 심리 공포 + 귀여움 + 애니 + 3D + 1인칭 (MiSide와 같은 조합) | 38 | 4개 (11%) | 3개 (8%) |

- 스팀 전체 평균 성공률(리뷰 1,000개 이상)이 약 3%인 것에 비하면 **두 묶음 다 높다.** 다만 인기 게임일수록 유저가 이런 태그를 더 붙이는 경향이 있어서 실제보다 높게 보일 수 있다.
- **3D 조합 38개 중 크게 뜬 건 MiSide 하나**다. 나머지 상위권: The Death | Thần Trùng 1,451, Saiko no Sutoka 1,390, Love Love School Days 1,091, Wolf Mate 635.

## 4. MiSide 이후 따라 나온 게임들 (실패에 가까운 패턴)
3D 조합에서 **2025~2026년에 나온 게임**은 대부분 영어 리뷰 수백 개 이하다.
| 게임 | 영어 리뷰 | 평가 |
|---|---|---|
| Wolf Mate (2025-08) | 635 | 94% |
| FUNKYHEART (2025-10) | 256 | 89% |
| Sabado (2026-11) | 229 | 87% |
| Playing House (2025-09) | 200 | 94% |
| KUMASAMA (2026-01) | 198 | 81% |

- **평가는 나쁘지 않은데 관심이 적다.** "나쁜 게임"이라서가 아니라 "또 하나의 귀여운 소녀 공포"로 묻혔다.
- 같은 장르의 얀데레(집착) 공포는 평가가 갈린다: Escape from Yandere 73%(영어 1,393), Yandere Virus 70%(241).
- 오래 끝나지 않는 개발도 실패 패턴이다: 얀데레 시뮬레이터는 개발이 10년 넘게 이어지며 신뢰를 잃은 대표 사례로 자주 언급된다(스팀 출시 아님).

**실패·묻힘의 원인 (위 사례와 리뷰 경향 정리)**
| 원인 | 설명 |
|---|---|
| 겉모습만 따라 함 | 귀여운 소녀 + 깜짝 놀래기만 있고 게임 구조가 얕다 |
| 반전이 이미 알려짐 | "귀여운데 사실 무서움"은 이제 모두가 아는 공식이다. 반전만으로는 놀라지 않는다 |
| 너무 짧음 | 1~2시간짜리는 영상 한 편 보고 끝난다 |
| 팬서비스가 앞섬 | 공포보다 노출을 앞세우면 평가가 갈린다 |
| 끝이 허무함 | 엔딩이 성의 없다는 불만은 MiSide에도 일부 있었다 |
| 범위 폭주 | 계속 늘리다 출시를 못 함 |

## 5. 성공작의 공통점
| 성공작 | 판매·반응 | 성공 이유 |
|---|---|---|
| MiSide | 추정 88만 장 | 한 캐릭터(미타)에 정이 듦 + 장면마다 다른 놀이 + 스트리머 반응 영상 + **출시 1년 전 itch.io 데모로 팬 확보** |
| DDLC | 무료 1,300만 다운로드, Plus 100만 장 | 캐릭터에 애착이 생긴 뒤 반전, 메타 연출 |
| Needy Streamer Overload | **300만 장 이상(공식, 2025-11)** | 귀여움 속 어두움, 한 캐릭터와의 관계, 엔딩이 많음 |
| The Coffin of Andy and Leyley | 추정 70만~150만 장, 영어 리뷰 1.9만 96% | 강한 두 캐릭터, 유튜브 실황으로 퍼짐 |
| Slay the Princess | 영어 리뷰 2.5만 96% | **회귀마다 다른 모습**, 선택이 변이를 정함 → 반복이 즐거움 |

**공통점 5가지**
1. **마음이 가는 캐릭터가 먼저.** 공포는 애착이 생긴 뒤에 온다.
2. **반전 말고도 "할 것"이 있다.** 장면별 놀이, 선택, 반복 구조.
3. **영상으로 퍼지는 순간이 있다.** 스트리머가 소리 지르거나 감정이 흔들리는 장면.
4. **엔딩·변형이 많아 다시 하게 만든다.**
5. **일찍 데모를 냈다.**

## 6. 우리 기획에 반영할 것
| # | 배운 것 | 우리 대응 |
|---|---|---|
| 1 | MiSide와 첫인상이 겹친다 | 첫 홍보 장면에 **여러 기숙생 + 규칙 쪽지 + 종족별 변이**를 함께 보여 준다. "또 하나의 미타"로 보이면 진다 |
| 2 | 반전만으로는 안 된다 | 반전을 숨기지 않는다. 공포를 처음부터 드러내고, 대신 **규칙 판단·이상현상 찾기·누구를 지킬지 고르기**를 핵심 재미로 둔다 |
| 3 | 애착이 공포를 키운다 | 이미 넣은 "호감도가 높을수록 변이 장면이 강하다" 규칙을 핵심으로 유지 |
| 4 | 반복 구조가 강하다 (Slay the Princess) | 회귀마다 **같은 기숙생이 다른 모습**으로 나오게 한다(선택·놓친 단서에 따라 변이 모양이 바뀜) |
| 5 | 영상으로 퍼져야 한다 | 기숙생마다 **"클립 한 장면"**을 설계한다(예: 구미호 꼬리가 복도를 메우는 순간). 깜짝 놀래기는 아끼고, 이 장면에 몰아준다 |
| 6 | 데모가 팬을 만든다 | 데모 = 기숙생 2~3명, 5~7일. 정식 출시 훨씬 전에 공개 |
| 7 | 범위 폭주가 가장 큰 실패 원인 | 정식판도 기숙생 6명 상한. 7번째(유령)는 이야기 장치로만 |
| 8 | 팬서비스 위주는 평가가 갈린다 | 매력은 성격·디자인으로, 수위는 컨셉 문서 추천안(바디 호러 위주, 연애 15세) 유지 |
| 9 | 규칙 괴담 신작이 나온다 | The Rules Kaidan: Night Watch(2027 1분기 예정) 출시 반응을 보고 차별점을 다시 점검 |
