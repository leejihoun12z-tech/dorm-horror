## 3. 작업 규칙 (저장소 CLAUDE.md에서 이 채팅에 해당하는 것)
- 한국어, 결론부터, 짧은 문장. 보고 = **처리한 내용 / 확인할 내용과 추천 / 다음 작업**.
- 상태 태그를 지킨다. [작업값]·[후보]를 [확정]으로 올리지 않는다. 사용자가 정한 것만 [확정].
- 그림·화면을 바꾸면 **직접 찍어서 보고 확인**한다. 부유·관통·잘림 같은 누가 봐도 이상한 결함은 먼저 고치고, 사용자에게는 취향과 방향만 묻는다.
- 정지 화면 확인은 "관찰"이다. 무서운지·매력적인지는 사용자가 보기 전까지 완료라고 하지 않는다.
- GPT로 그림 받을 때: 한 요청 한 컷, 규칙 지시문을 새 창 첫 메시지로. 방식은 던전 게임의 `docs/art-gpt-request-spec.md`를 참고만 한다(검수 코드 등).
- 문서를 고치기 직전에 최신 파일을 다시 읽고, 자기 변경만 더한다. 다른 채팅이 쓴 내용은 지우지 않는다.
- 의미 있는 변경 뒤에는 `docs/STATUS.md`의 「새 게임 기획」 줄 끝에 한 줄 덧붙이고, 커밋·push 한다(CLAUDE.md 자동 올리기).
- `docs/handoff/`는 고치지 않는다.
- 권리·결제·키 규칙은 아트 바이블 §5.
