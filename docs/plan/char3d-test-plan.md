## 1. 결론
- **시험 장면 틀은 준비 끝.** 지금은 대역 몸(상자 사람)으로 돌아간다. 실제 로우폴리 모델이 오면 `character_scene` 하나만 바꾸면 같은 시험이 된다.
- **남은 건 실제 몸과 얼굴 그림이다.** 사용자 결정 3개(§5)가 있어야 시작한다.

## 4. 몸 만드는 길 [후보]
| 안 | 내용 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **A. Tripo 웹 (추천)** | 전신 그림 → 로우폴리 생성 → 자동 리깅 → glb | 우리 디자인(머리 모양·귀·꼬리)이 바로 반영됨. 리깅이 같이 나옴 | 사용자가 크롬에서 Tripo 로그인. 무료판 결과물은 상업 불가 → **시험용만**. 무료판에서 로우폴리·리깅이 되는지 [확인 필요] |
| B. 무료(CC0) 기본 몸 + Blender | 무료 공개 사람형 몸을 받아 5.5등신으로 고치고 머리카락·귀·꼬리 덩어리를 붙임 | 상업 가능, 결제·로그인 없음 | 머리카락 덩어리 모양을 Claude가 눈으로 깎는 일이 많음(잘 못 하는 일, tech-plan §5-1) |

- 걷기·대기 동작: A는 Tripo 자동 리깅의 기본 동작이 되는지 먼저 본다. 안 되면 무료(CC0) 사람형 동작 묶음을 받아 옮겨 씀(받기 전에 파일·출처·크기·라이선스를 보여 드리고 승인받음).
- 권리 규칙(art-bible §5): Hunyuan3D 안 씀 · Fab "NoAI" 상품을 AI 입력에 안 넣음.
