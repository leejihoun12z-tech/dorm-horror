## 3. 추천
**1번 Minimoku "Anime Base Mesh - Female Character"를 Fab에서 구매 ($34.99).**
- 얼굴 그림체가 후보 중 가장 서브컬처 게임에 가깝다.
- 표정 변형 153개로 대화 표정·입 모양을 다 덮는다.
- 텍스처 원본(PSD)이 있어 눈·피부 그림을 캐릭터마다 바꿔 그릴 수 있다.
- Fab 표준 라이선스는 상업 게임 사용, 수정, 엔진 제한 없음, 판매 수 제한 없음이 명시돼 있다. 같은 상품이 CGTrader에서는 $60이다.
- 같은 작가가 머리카락 세트도 따로 판다(조립 시험에 쓸 수 있음).

## 4. 꼭 알아야 할 조건: "AI 금지" 표시
- 1·2번은 Fab에서 **"AI 사용 허용: 아니오(NoAI)"**이고, 판매자 조건에 "AI 학습 데이터로 사용 금지"가 있다.
- Fab 이용약관: NoAI 콘텐츠를 생성 AI의 **데이터셋·개발·입력**으로 쓰면 안 된다. (Fab EULA에는 "학습 입력"이라고 적혀 있어 두 문서의 표현이 다르다는 지적이 있다. 안전하게 넓은 쪽으로 해석한다.)
- **우리 방식에서 지킬 것**
  | 하는 일 | 가능? |
  |---|---|
  | 베이스를 Blender에서 고치고, AI가 만든 머리카락·옷 부품을 붙여 게임에 넣기 | 가능 (AI에 베이스를 넣지 않음) |
  | 베이스 파일·렌더 그림을 Meshy·Tripo·GPT 이미지에 **입력으로 넣기** | **하지 않는다** |
  | AI 학습에 쓰기 | 하지 않는다 |
- 영향: `ai-3d-pipeline.md` §3의 "마스터 몸을 찍은 그림 위에 AI가 덧그리기"는 **베이스 렌더 대신 Claude가 직접 그린 비율 안내선 그림(머리 크기·어깨·허리·다리 길이 표시)**으로 바꾼다. 옷의 뼈 영향값 옮기기도 AI 도구가 아니라 Blender에서 한다.
- 더 확실히 하려면: 판매자(상품 페이지에 문의 메일 있음)에게 "AI로 만든 옷·머리카락 부품을 이 베이스에 붙여 상업 게임에 쓰는 것"이 괜찮은지 한 줄 문의하고 답을 보관한다. [추천]

## 5. 그 밖에 확인 못 한 것
- 실제 파일의 면 흐름, 얼굴 그림자 지도용 UV, Godot로 옮겼을 때의 상태 → 구매 후 관문 2에서 확인
- 연애 대상은 성인 설정이다. 1번 몸은 성인 비율로 보인다(그림 기준).
- 7번 확장 라이선스 가격, 8번 실제 라이선스 문서
- Booth 상품(같은 Minimoku 상품이 Booth에도 있음)은 페이지를 읽지 못했다.
