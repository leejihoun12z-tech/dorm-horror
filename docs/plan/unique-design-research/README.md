## 1. 왜 지금 그림이 평범한가 (원인 5)
1. **학습 그림에 많은 쪽으로 끌려감** — `brown hair` 216만 장 · `long hair` 644만 장 ↔ `jellyfish girl` 459장. 몬스터 태그는 수백 배 적다.
2. **비워 둔 칸은 기본값으로 채워짐** — 머리색을 안 쓰면 갈색, 피부를 안 쓰면 살색, 아래옷을 안 쓰면 흰 셔츠+치마.
3. **우리 모델(Anima Aesthetic)이 「일관된 기본 화풍」으로 다듬은 판** — 공식 설명상 다양성은 Base 판이 가장 크다.
4. **옷 설명이 길면 앞쪽 종족 정보가 묽어짐** — 커뮤니티 권장 200토큰 안.
5. **전신 1024×1536이면 눈이 15~25px** — 특별한 동공을 써도 뭉개져 둥근 눈으로 돌아간다.

## 3. AI로 뽑는 법 — 작업 순서 [후보]
1. **디자인 카드 먼저(사람)**: 캐릭터마다 「눈에 박히는 3가지」 + 칸 전부(피부·머리 모양·머리 2색·눈·옷 실루엣 1·디테일 1·소품 1·팔레트).
2. **상반신으로 탐색**: `upper body`/`cowboy shot` · 8 seed · 태그 40~60개·200토큰 안 · Aesthetic ↔ Base 계열(우리 PC엔 Nya-Iris Base1 기반판) 같은 seed로 비교.
3. **고르고 고치기**: 가장 센 1장 → 머리·눈만 inpaint(머리 0.6 · 눈 0.4~0.6).
4. **전신으로 옮기기**: 고른 그림 img2img 0.5~0.65, 또는 우리 스케치 → LLLite any-test(우리 PC에 있음).
5. **얼굴·눈 다시 그리기**: FaceDetailer(얼굴 0.26 · 눈 0.24) — **Impact Pack 설치 필요(지금 없음)**.
6. **마무리**: Aesthetic + L5 LoRA로 img2img 0.3~0.4(화풍만 통일).

### 프롬프트 쓰는 법
- 순서: 종족·몸 → 피부 → 머리 모양 → 머리 색 → 눈 → 옷 실루엣 1 → 디테일 1 → 소품 1 → 팔레트 → 자세·배경 → 태그로 안 되는 것만 짧은 문장 1~2줄.
- **실제 있는 Danbooru 태그**로(문장보다 셈). 없는 이름 예: `pink inner hair` → `colored inner hair, pink hair` · `silver hair` → `grey hair` · `transparent hair` → `see-through hair` · `red tips` → `colored tips, red hair`.
- 여러 색 머리 = 종류 태그 + 각 색 + 색 붙은 태그: `streaked hair, white hair, red streaks`.
- 피부 = `colored skin, blue skin` 두 개 같이.
- 색은 물건 바로 앞(`black jacket`), 한 캐릭터 색 낱말 4~5개 이하.
- 그림 수 1천 미만 태그(`jellyfish girl`, `bee girl`)는 큰 태그 여러 개로 쪼갬.
- 부정 프롬프트엔 **실제로 나온 기본값만**(`brown hair` 등). Aesthetic에선 `score_*`를 긍정·부정 양쪽에 다 넣지 않음.
