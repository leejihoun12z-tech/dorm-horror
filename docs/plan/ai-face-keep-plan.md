# AI 얼굴을 그대로 살리는 방법 (얼굴 교체 안 함)

_작성: 2026-11-20 · 사용자 지시: "얼굴을 바꾸면 퀄도 낮아지고 다 비슷해진다. 안 된다고 하지 말고 방법을 찾아봐" · 상태: [후보], 시험 전_
_관련: `ai-3d-pipeline.md`(전체 제작 방식), `subculture-model-research.md`(실제 게임 자료). 이 문서는 ai-3d-pipeline §5 "공용 마스터 얼굴로 교체"를 대체하는 안이다._

---

## 1. 결론
**얼굴 모양은 캐릭터마다 AI가 뽑은 것을 그대로 쓴다. AI 얼굴의 약점 3가지(지저분한 면, 울퉁불퉁한 명암, 표정 없음)만 뒤에서 고친다.**
- 개성 = AI 얼굴 모양 + 캐릭터별 2D 눈·눈썹·입 그림 → 캐릭터마다 다르다
- 품질 = 깨끗한 면 구조 + 그림처럼 깨끗한 명암 + 표정 → 서브컬처 게임 방식과 같다

## 2. AI 얼굴의 약점과 해결
| 약점 | 원인 | 해결 방법 | 얼굴 모양이 바뀌나 |
|---|---|---|---|
| 얼굴 디테일이 뭉개짐 | 전신을 한 번에 뽑으면 얼굴에 해상도가 적게 감 | **머리만 따로 고해상도로 뽑는다** (§3-1) | 아니요, 더 정확해짐 |
| 면 구조가 지저분함 | AI는 면을 아무렇게나 만든다 | **면 구조 씌우기** — 깨끗한 면 틀을 AI 얼굴 모양에 맞춰 씌운다 (§3-2) | 아니요 |
| 명암이 울퉁불퉁, 각도마다 인상이 다름 | 작은 굴곡이 그대로 그림자로 나옴 | **명암용 노멀 옮기기** + **얼굴 그림자 지도** (§3-3) | 아니요, 빛만 바뀜 |
| 표정이 없음 | AI 모델에는 표정 변형이 없다 | **표정 옮기기(3D)** + **2D 표정 그림 교체** (§3-4) | 아니요 |
| 원화의 그림자가 구워짐 | AI가 원화 명암을 텍스처에 넣음 | 평면 색 원화를 다시 투영, 눈은 따로 그림 (§3-5) | 아니요 |

## 3. 단계별 방법

### 3-1. 머리만 따로 고해상도로 뽑기
- GPT로 **머리만** 그린 삼면도(정면·측면·뒷면)를 따로 만든다. 그림자 없는 평면 색, 고해상도, 단색 배경.
- Meshy 7.1 Ultra 4K(정밀 형상 모드, 한 장 입력) 또는 여러 장 입력으로 머리만 생성한다.
- 전신 모델의 머리 자리에 붙인다. 목 이음새는 Blender에서 합친다.
- 효과: 얼굴에 폴리곤과 텍스처 해상도가 몰린다. 실제 게임도 머리에 자원을 절반 이상 쓴다(학원 아이돌마스터).

### 3-2. 면 구조 씌우기 (모양은 AI 것, 면은 깨끗하게)
- 깨끗한 애니 얼굴 면 틀 1개를 준비한다(구매한 베이스 또는 직접 만든 틀).
- 틀을 AI 얼굴에 맞춰 늘려 씌운다. 눈꼬리·입꼬리·코끝 등 기준점 10~20개를 맞추고 표면에 붙인다.
- **결과: 얼굴 모양은 AI 얼굴 그대로, 면 구조·UV는 모든 캐릭터가 같은 깨끗한 틀.** 학원 아이돌마스터가 "모든 캐릭터 얼굴 면 구조 공통"인 것과 같은 상태가 된다. 하지만 모양은 캐릭터마다 다르다.
- 도구 후보: B-Skin(Blender, 기준점 + 감싸기 + AI 텍스처를 새 UV로 굽기), Wrap for Blender, BWrap, R3DS Wrap(전문 도구, 유료)
- 주의: 판매 베이스를 틀로 쓸 때 — Blender 안에서 변형만 하므로 "AI에 입력"이 아니다. 베이스 파일이나 렌더를 AI 도구에 넣지 않는 규칙은 그대로 지킨다.

### 3-3. 명암을 그림처럼 깨끗하게 (모양은 그대로)
- **명암용 노멀 옮기기:** 매끈한 대리 얼굴(공 모양에 코·턱만 살린 형태)의 노멀을 AI 얼굴에 옮긴다. 모양은 그대로인데 빛은 매끈한 면처럼 받는다 → 작은 굴곡 그림자, 각도마다 바뀌는 인상이 사라진다. 애니풍 업계에서 널리 쓰는 방법(Blender 기본 기능 Data Transfer).
- **얼굴 그림자 지도:** 빛이 0~180도로 돌 때 얼굴 그림자 모양을 9장 정도 만들어 하나의 지도로 합친다. 원신식 얼굴 그림자. 대리 얼굴로 9장을 자동 렌더 → 합치기까지 스크립트로 자동화한다. 마음에 안 드는 각도만 손으로 고친다.
- **각도별 보정(선택):** 옆에서 볼 때 코를 살짝 넣는 등, 카메라 각도에 따라 얼굴을 조금 바꾸는 변형(학원 아이돌마스터 방식).

### 3-4. 표정 만들기 (두 방법을 섞는다)
**A. 3D 표정 옮기기 (입 벌리기, 눈 감기, 뺨·턱 움직임)**
- 3-2에서 면 구조가 틀과 같아졌으므로, 틀의 표정 변형(구매 베이스 1번은 153개)을 각 캐릭터 얼굴 모양에 맞춰 옮긴다. 얼굴 비율 차이가 크면 몇 개는 손으로 고친다.
- 자동 생성 도구 후보: FaceKeys Full(이미지→3D 머리에 ARKit 52개 표정 자동 생성, 애니 머리용 안내 모드), Faceit(기준점 찍고 52개 반자동 생성)
- 연구 단계 후보: **OmniFaceRig**(Meta, 2026-11): 표정 없는 생성 모델 하나를 넣으면 표정 변형 최대 155개와 입 속(이·혀)까지 **완전 자동**으로 만든다. 사람·사람형·여우·고양이 같은 동물 얼굴까지 지원 → 인외 기숙생(구미호 등)에 특히 맞다. 공개 범위(코드·사용 조건)는 확인 필요, 그래픽카드 필요.

**B. 2D 표정 그림 교체 (애니 감성의 핵심)**
- 눈·눈썹·입을 그림으로 그려 얼굴에 덧입히고, 표정마다 그림을 바꿔 끼운다(그림 묶음에서 칸 이동).
- GPT로 캐릭터마다 **표정 시트**(기쁨·화남·슬픔·놀람·부끄러움·공포·윙크 등)를 같은 그림체로 그린다 → 눈 부분만 잘라 정리.
- 눈은 홍채·흰자·하이라이트 3층으로 나눠 하이라이트가 따로 움직인다(글썽임, 공포로 하이라이트가 꺼지는 연출).
- 덧그림: 홍조·창백·눈물·식은땀·만화 눈(우마무스메 방식).
- **이 방식이면 표정 품질 = 2D 일러스트 품질이고, 캐릭터마다 완전히 다르다.**

**섞는 규칙:** 눈꺼풀·입 벌림·턱·뺨은 3D(A), 눈동자·눈썹·입 모양 디테일·홍조는 2D(B).

### 3-5. 텍스처 정리
- AI가 구운 명암 텍스처는 버린다(실제 서브컬처 게임은 노멀맵·구운 명암을 안 쓴다).
- 평면 색 정면 원화를 얼굴에 다시 투영하고, 안 보이는 곳은 AI 텍스처 색으로 채운다.
- 3-2 덕분에 모든 캐릭터의 얼굴 UV가 같다 → 2D 표정 그림, 홍조 위치, 얼굴 그림자 지도 틀을 캐릭터끼리 재사용할 수 있다.

## 4. Claude가 직접 할 수 있는 범위
| 단계 | Claude 직접 | 사람 손 |
|---|---|---|
| 삼면도·표정 시트 요청문 | 작성 | GPT 실행(사용자 또는 Claude 크롬) |
| AI 3D 생성 | API 키가 있으면 직접 | 없으면 사용자가 웹에서 |
| 면 구조 씌우기 | Blender 스크립트(기준점 좌표 지정) | 기준점이 어긋난 곳 확인 |
| 노멀 옮기기·그림자 지도 굽기 | 스크립트로 자동 | 이상한 각도만 확인 |
| 표정 옮기기 | 스크립트 + 도구 | 깨진 표정 몇 개 손보기 |
| 2D 표정 정리·합치기 | 잘라 붙이기·정리 스크립트 | 마음에 드는 표정 고르기 |
| Godot 셰이더·촬영 | 직접 | 판정 |

## 5. 시험 계획 (말보다 그림으로 확인)
| 순서 | 내용 | 필요한 것 |
|---|---|---|
| 1 | GPT로 기숙생 2명의 **머리 삼면도** + 표정 시트 | GPT |
| 2 | Tripo 또는 Meshy 무료판으로 머리 2개 생성 (시험은 비상업이라 무료판 가능) | 사용자가 웹에서 뽑아 GLB 전달, 또는 API 키 |
| 3 | Claude: 그대로 렌더 vs 노멀 옮기기 + 그림자 지도 + 2D 눈 적용 렌더를 나란히 | 이 작업 환경 |
| 4 | 2명을 나란히 놓고 "서로 다르게 보이는가, 그림처럼 보이는가" 판정 | 사용자 |
| 5 | 통과하면 면 구조 씌우기 + 3D 표정 옮기기 시험 | 마스터 베이스 또는 직접 만든 틀 |

- 1~4단계는 **결제 없이** 할 수 있다(무료판 + 이 작업 환경).

### 5-1. 시험 꾸러미 준비 끝 (2026-11-20)
- 사용자 지시 "던전 게임 캐릭터 디자인으로 준비" → 비서(채택본·표정 7종 있음) + 보물 담당 골드 드래곤 B안(인외 부위 큼)
- 꾸러미 `assets/art_wip/char3d_test_20261120/README.md` (GPT 요청문·무료판 3D 생성 방법·저장 이름), 검사 도구 `tools/char3d_check/`

## 6. 위험과 대책
| 위험 | 대책 |
|---|---|
| AI 머리 모양 자체가 이상함 (좌우 비대칭, 눈 위치) | Blender에서 좌우 대칭 맞추기 스크립트, 그래도 안 되면 다시 뽑기 |
| 면 구조 씌우기에서 눈·입 주변이 어긋남 | 눈·입 테두리를 고리 단위로 맞추는 기능(B-Skin 등) 사용 |
| 얼굴 비율 차이가 커서 표정이 깨짐 | 2D 표정 비중을 높이고 3D는 눈꺼풀·입 벌림만 |
| OmniFaceRig 코드 미공개 | FaceKeys·Faceit·직접 옮기기로 대체 |
