## 주의
- 「조각·층」 연출은 그림을 층(눈·입·목·옷·선화)으로 나눠야 함 → 1단계 그림을 고른 뒤 층 나누기를 같이 함.
- 한 캐릭터에 연출을 다 쓰지 않음 — 캐릭터마다 대표 연출 1~2개(예: 마네킹 = 지우개, 우물 원혼 = 젖어 번짐, TV 머리 = 해상도·색판, 저주 계열 = 낙서).
