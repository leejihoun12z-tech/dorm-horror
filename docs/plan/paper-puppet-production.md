## 1. 레퍼런스 4개 — 어떻게 만들었고 우리가 배울 점
| 게임 | 만든 방식 (제작사·기사 확인) | 우리가 가져올 점 |
|---|---|---|
| **Mouse: P.I. For Hire** (Fumi Games, 2026, Unity) | 배경 = 3D, 적·NPC·무기·UI = 손그림 2D. 캐릭터는 최대 8각도, 적 1종 약 400장, 게임 전체 약 54,000장. **2D 캐릭터에는 조명을 안 씀**("늘 같은 모습으로 보이게"). 배경은 회색조·외곽선 없이 "배경일 뿐"으로 낮춤, 만질 수 있는 것만 외곽선. 장 수가 많아 메모리가 가장 큰 문제였다고 함 | 캐릭터를 배경보다 또렷하게(배경 대비 규칙) · **장 수를 처음부터 계산**(우리는 각도 대신 앞·뒤 + 상황이라 훨씬 적음) · 빛을 얼마나 받을지 정하기(아래 §2-6) |
| **Fallen Aces** (New Blood, Unity) | 2D 손그림 캐릭터 여러 각도 + 3D 세계. 배경 텍스처는 사진을 섞고 포토샵 "오려내기(cutout)" 필터로 만화 느낌. 캐릭터 동작은 사진·영상을 따라 그림(로토스코프), 최근 것은 **3D 모델을 2D 그림으로 바꿔서** 만듦. 스팀 토론에서 "AI 텍스처 아니냐" 의혹 → 개발자가 직접 해명 | 배경도 같은 "그린 듯한" 손질을 거치면 캐릭터와 섞임 · **AI 의혹 반발이 실제로 있음** → AI 고지·사람 손질 범위를 미리 정함 |
| **Forgive Me Father** (Byte Barrel) | 3D 세계 + 만화책 같은 손그림 2D 적. "납작한 그림을 3D인 척하지 않고 납작함을 강조"하기로 함. 적이 맞으면 **그림이 바뀌어 상태가 달라짐**(반으로 잘림 등) | 우리 "상황 그림 바꾸기"와 같은 생각 · 종이임을 숨기지 말고 드러냄(칼선·두께·뒤집기) |
| 2번 (픽셀 레트로 슈터, 이름 확인 못 함) | 3D 세계 + 저해상도 픽셀 2D. 화면 전체 해상도를 낮춰 2D·3D가 같은 결로 보임 | 화면 전체에 같은 후처리(입자·색 보정)를 걸면 2D·3D가 한 그림처럼 묶임 |

**공통 교훈:** 4개 모두 **배경과 캐릭터를 하나의 "그림 언어"로 묶는 장치**가 있다(만화 셰이더·오려낸 텍스처·흑백·저해상도). 우리는 "고퀄 3D 맵 + 종이 카드"라서 묶는 장치를 따로 정해야 한다 → §3-4.

## 2. 그림체·캐릭터 디자인을 최대한 똑같이 유지하는 법
목표: 1명당 약 10장(앞·뒤 + 상황 6~8 + 고유 1~2)이 **같은 사람, 같은 그림체, 같은 크기**로 보이게.

### 2-1. 순서 [후보]
1. **기준 그림(히어로) 1장 확정** — 정면 전신 + 얼굴 확대. 이후 모든 그림은 "직전 결과"가 아니라 **늘 이 기준 그림에서** 출발(고친 그림을 또 고치면 틀어짐이 쌓임).
2. **디자인 확인표** — 캐릭터마다 바뀌면 안 되는 것 5~8줄: 머리 모양·앞머리 갈래·눈 색·소품 위치·인외 부위(뿔·꼬리·입) 위치·옷 단추 수. 색은 **HEX 팔레트 6~10색**으로 고정.
3. **3면도(앞·옆·뒤) + 높이 가로선** — 눈·턱·어깨·허리·발 높이를 선으로 맞춤(스카우트 ◎). 뒷모습 카드가 여기서 나옴.
4. **공용 자세표** — 상황 8개 자세를 뼈대(OpenPose 막대 그림)로 한 번 만들어 **모든 캐릭터가 같이 씀**. 같은 자세 = 세트 통일감 + 발 위치·키가 저절로 맞음.
5. **만들기** (아래 2-2 중 하나) → 한 장에 **한 가지만 바꿈**(자세만, 그다음 표정만).
6. **검수** — 기준 그림과 나란히 크게 놓고 확인표 대조. 틀어진 그림은 **고치지 말고 다시 뽑기**.
7. **마무리 자동 처리** — 바탕 지우기·흰 칼선(`tools/dev/make_paper_cards.py`)·발끝 맞추기·팔레트 밖 색 검사(던전 `qa_check.py` 방식).

### 2-2. 만드는 길 3가지
| 길 | 어떻게 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **A. 편집 모델 + 기준 그림** (추천 시작) | 기준 그림 + 자세 뼈대(또는 말)로 "이 사람 그대로, 자세만 바꿈". 로컬 **Qwen-Image-Edit 2511**(Apache 2.0, ComfyUI) 또는 GPT 이미지 편집 | 학습 없이 바로 · 10장 정도면 충분 | 얼굴·작은 장식이 조금씩 흔들림 → 검수로 거름. 8GB에서 속도 [확인 필요] |
| **B. 캐릭터 LoRA** (메인 캐릭터용) | A로 만든 좋은 그림 15~30장(앞·옆·뒤·표정 섞어)으로 캐릭터 전용 LoRA 학습 → 아트 채팅의 **그림체 LoRA(L5)와 같이** 씀 + 자세 뼈대(ControlNet) + 같은 시드 | 장 수가 많아도 얼굴이 단단히 고정 · 나중에 추가 그림이 쉬움 | 1명당 학습 1~2시간 · 학습용 그림을 먼저 모아야 함 |
| **C. 3D 인형 자세 → 덧칠** (스카우트 "Anton 방식") | 이미 있는 Tripo 마네킹(뼈대 있음)으로 자세를 잡아 찍고, 그 위에 AI가 그림체로 덧칠 | 자세·비율이 정확(AI가 자세를 망치지 않음) · 3D 작업이 헛되지 않음 | 캐릭터마다 3D 모델이 있어야 함 |
- **추천:** 메인 6명 = A로 시작 → 좋은 그림이 모이면 B로 굳힘 · 조연 = A만 · 엑스트라 = 앞·뒤 2장만. 마네킹처럼 3D가 이미 있는 캐릭터는 C도 시험.
- 그림체 자체는 아트 채팅이 고른 L5(+C7)를 기준으로 — `style-models-loras-20261120.md`(MyGodotGame `docs/new-game/`) §9~11.

### 2-3. 그림 규칙 (세트끼리 튀지 않게)
1. 캔버스 같은 크기, **발바닥 = 그림 맨 아래 같은 줄**, 머리끝 위치도 같은 키 기준.
2. 그림 안 그림자는 약하게(빛 방향 없는 고른 빛) — 3D 맵 조명이 위에 입혀짐.
3. 뒷모습 외곽은 앞모습과 거의 같게(종이 두께가 겹치는 곳에만 생김).
4. 앉기·눕기 그림은 기준점 따로: 앉기 = 엉덩이 높이, 눕기 = 카드를 바닥·침대에 눕힘.
5. 대화 화면 그림 = 같은 세트의 상반신·표정판. 입간판과 대화 그림이 다른 사람처럼 보이면 안 됨.

### 2-4. AI 고지·반발 대비
- Fallen Aces도 "AI 아니냐"는 의혹을 받음 → 우리는 **스팀 AI 고지에 그림 AI 사용을 정직하게 적고**, 사람이 한 일(디자인·검수·손질)을 같이 적는다(스카우트 "스팀 AI 고지" 틀).
- 권리: Hunyuan·MiniMax 계열 금지, 비상업 모델 금지, Fab "NoAI" 상품을 AI 입력에 넣지 않음(art-bible §5).

### 2-5. 장 수·메모리 [작업값]
- 27명 기준 약 250~300장. 한 장 세로 약 1,500px면 압축 전 1장 약 9MB, 압축(VRAM 압축) 뒤 약 1/4~1/8. **그날 나오는 캐릭터만 불러오기**로 충분할 것 [확인 필요].

### 2-6. 빛을 받을까
- 지금 시안: 카드가 장면 빛을 받음(밤 손전등이 비추는 맛). Mouse P.I.는 반대(빛 안 받음 = 늘 같은 모습).
- 추천: **기본은 빛 받음 + 최소 밝기 하한**(어두운 곳에서도 얼굴이 묻히지 않게). 밤 공포 연출 때 일부러 하한을 없앰.

## 3. 평소 = 빌보드 말풍선 + 짧은 음성
### 3-1. 말풍선 (구현함 — 정지 화면 확인)
- `PaperPuppet.say("글", 음성, 초)` → 머리 위에 종이 말풍선(흰 바탕·검은 테두리·꼬리)이 톡 튀어나왔다가 사라짐. 그림 `img/paper_puppet_20261127/speech_bubble.jpg`.
- 규칙 [작업값]: 한 줄 · 14자 안팎 · 2~3초 · 가까이(약 6m 안)에서만 · 여러 명이면 한 명씩. 긴 대화는 대화 화면으로 넘김.
- 남은 일: 진짜 한글 글꼴(지금은 시스템 글꼴), 말풍선 종이 질감, 거리 따라 크기 유지, 겹침 방지.

### 3-2. 짧은 음성 — 3가지 방식
| 방식 | 예 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **V1. 진짜 목소리 감탄사** (추천) | "응?", "아!", "사감님~", 웃음, 한숨 — 캐릭터당 5~8개, 말풍선과 함께 하나 재생 | 캐릭터 매력이 큼 · **밤에 같은 소리를 느리게·거꾸로·겹쳐 틀면 공포**(스카우트 "짧은 목소리로 섬뜩하게") | 녹음 또는 TTS 필요 |
| V2. 옹알이(동물의 숲·언더테일식) | 글자가 나올 때마다 짧은 소리, 캐릭터마다 음높이 다름 | 대사 수와 상관없이 소리가 남 · 만들기 쉬움(합성) | 귀여움 쪽으로 쏠림, 우리 톤과 맞는지 [확인 필요] |
| V3. 둘 섞기 | 첫마디는 감탄사 1개 + 나머지는 옹알이 | 매력 + 분량 해결 | 조절이 필요 |
- 목소리 출처 후보: 성우 외주(가장 좋음) · 상업 가능 TTS(Chatterbox·Qwen3 TTS — 스카우트) · 効果音ラボ 음성(상업 OK, 재배포·AI 학습 금지). 한국어 TTS 감탄사가 자연스러운지 시험 필요.
- 구현: `voice_pitch`(캐릭터마다 음높이)와 3D 소리 재생 자리를 노드에 넣음. 소리 파일은 아직 없음(들어 보기 전).

### 4-2. "고퀄"로 보이게 하는 것 (배경 점검표 [후보])
1. **빛**: 형광등 색 온도(낮 흰빛·밤 녹색 끼), 몇 개만 깜빡임, 비상구 초록 불, 창밖 가로등. 빛이 반이다.
2. **생활감 소품**: 신발장·우편함·게시판 종이·소화기·분리수거함·빨래 건조대·방문 이름표 — 한국 기숙사 사진에서 목록을 뽑음.
3. **때·얼룩**: 데칼(바닥 자국·벽 얼룩·테이프 자국), 모서리 먼지.
4. **반사**: 왁스 칠한 바닥의 흐린 반사(반사 프로브).
5. **공기**: 옅은 볼류메트릭 안개·먼지(손전등 빛줄기가 보임).
6. **화면 마무리**: 필름 입자·색 보정·비네트 — **카드와 배경을 같이 묶는 장치**(§1 공통 교훈).
7. **소리**: 형광등 웅웅·환풍기·먼 문소리. 소리가 배경 품질의 절반.

### 4-4. 배경 재료 (사용권)
- **Poly Haven · ambientCG**: 텍스처·HDRI·모델 CC0(상업 무료, 표기 없음).
- **Polyfork**: 무료 로우폴리 3,599개(스카우트) — 먼 배경 채우기용.
- **Fab**: 배경 소품으로 쓰는 건 상품별 라이선스 확인 · "NoAI" 상품은 AI 입력에 넣지 않음.
- **직접 찍은 기숙사 사진** → 텍스처(Fallen Aces식 사진 섞기). 가장 한국 기숙사다움.

### 4-5. 묶는 장치 정하기 (사용자 결정)
"고퀄 3D 맵 + 종이 카드"를 한 그림으로 묶는 법:
- **(가) 진짜 같은 기숙사 + 종이 인형** — 일부러 대비. "실제 공간에 종이 주민이 산다"는 것 자체가 이상함(공포에 유리). 화면 입자·색 보정만 같이.
- (나) 배경도 그림처럼 — 배경 텍스처를 그린 듯 손질(Fallen Aces식), 카드와 결을 맞춤. 공포보다 아늑함 쪽.
- 추천: **(가)** — 낮엔 따뜻한 실사풍 기숙사에 귀여운 종이 주민, 밤엔 같은 공간이 어두워지며 종이라는 게 오히려 섬뜩해짐.
