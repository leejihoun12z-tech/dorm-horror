# 배에 입 → 뒤통수 입으로 바꿈 (2026-11-25, 그리기 전 · [후보])

사용자 11-25: 「배에 입 아예 바꾸자, 전에 뒤통수 쪽에 입 있는 거 만들었잖아 그쪽으로 준비 · 디자인 색조합 아예 바꿔서」.
예전 시험: 「후타바」(char-pilot3-20261120.md §2-2 — 노랑·검정, 큰 노란 리본이 입 뚜껑, 식품영양, 소식좌인데 냉장고 음식이 사라짐) · 그림 `futaba_flat_20261121/`.
원전: 후타쿠치온나 — 뒤통수의 둘째 입, 머리카락이 손처럼 움직여 음식을 나름, 어떤 이야기에선 뒤 입이 **듣기 싫은 진실을 외침**(occult-candidates §출처).
입 모양 규칙(사용자 11-25): 입술 없이 **만화식 상어 이빨 또는 들쭉날쭉한 괴물 입**.

## 1. 새 디자인 — 「속마음이 뒤통수로 새는 상담심리학과」
| 항목 | 내용 |
|---|---|
| 한 줄 | 앞 입은 상냥한 말만 하는데, 뒤통수 입이 **속마음과 남의 비밀**을 다 말해 버림 |
| 학과 | 상담심리학과 3 (또래 상담 동아리) |
| 실루엣 훅 | 뒤통수를 **커다란 진주빛 헤어 집게(헤어 클로)**로 집어 둠 — 사실은 뒤 입을 억지로 다물게 하는 것. 집게 사이로 이빨이 살짝 비침 |
| 뒤통수 입 | 머리카락 사이로 가로로 벌어지는 들쭉날쭉한 이빨 입(입술 없음) · 안쪽 산호색 · 긴 혀 |
| 머리 = 몸 | 반묶음 긴 머리, **끝 가닥들이 손가락처럼 갈라져** 물건을 집음(원전의 「머리카락 손」) |
| 얼굴 | 졸린 듯 상냥한 눈 · 앞 입은 늘 작게 웃음 · 뒤 입이 말할 땐 앞 얼굴이 당황 |
| 옷 | 오버사이즈 니트 카디건 + 셔츠 칼라 + 롱스커트 · 상담 노트 · 목에 상담 동아리 명찰 |
| 구도 | 반쯤 뒤돌아 어깨 너머로 봄(앞 얼굴과 뒤통수 입이 한 장에 같이) |

## 2. 색조합 (노랑·검정 → 아예 바꿈)
| 안 | 머리 · 옷 · 입속 | 느낌 | 명단과 겹침 |
|---|---|---|---|
| **K1 짙은 청록 · 크림 · 산호 ★추천** | 짙은 청록(딥 틸) 머리 · 크림 니트 + 회청 스커트 · 산호 입속 | 차분한 상담사 → 뒤 입 산호가 튐 | 클리오네·슬라임(밝은 물색)보다 훨씬 어두워 구별됨 |
| K2 남보라 · 민트 · 산호 | 인디고 머리 · 민트 니트 · 산호 입속 | 서늘하고 몽환적 | 별을 삼킨 아이(남색·보라 머리)와 비슷 |
| K3 은회색 · 머스터드 · 진홍 | 은회 머리 · 머스터드 니트 · 진홍 입속 | 빈티지 | 흰 계열 머리가 많은 명단과 겹침 · 진홍은 빨간 마스크와 겹침 |

## 3. 공포 단계 · 수칙
- 낮: 고민을 잘 들어 주는 상담 동아리 선배 — 머리 집게를 절대 안 풂.
- 밤: 등 뒤에서 내 비밀을 속삭이는 소리 — 돌아보면 그녀는 등을 보이고 서 있음.
- 정체: 집게가 풀리고 뒤 입이 웃으며 내 이름과 속마음을 말함 · 머리카락 손이 문고리를 돌림.
- 수칙: 「뒤돌아 서 있는 기숙생에게 말 걸지 말 것」.

|---|---|

## 7. GPT 디자인 → 우리 화풍 (2026-11-25 사용자 「GPT로, 입 더 크게, 여러 개」)
- 크롬 ChatGPT에 한 요청 한 장으로 4장: ① 청록·크림 ② 같은 색, 입을 더 크게(정수리~목 아래) ③ 남보라·민트 ④ 은회·머스터드(거의 등을 보임). 그림 `assets/art_src/dorm/backmouth_gpt_20261125/backmouth_gpt_1~4.png`.
- GPT 결과: **4장 모두 뒤통수가 세로로 갈라진 큰 입**(검은 속·흰 송곳니·진주 헤어 집게·잇몸 없음) — 글만으로 우리 모델이 못 하던 자리·모양이 한 번에 나옴.
- 우리 화풍으로 다시(`gen_backmouth_gpt.py`, `BMG_n_45/60`): 0.45 = 입 모양·구도 그대로, 화풍만 우리 쪽 · 0.6 = 화풍 더 강함, 대신 헤어 집게가 해골 장식으로 바뀌고 입 테두리가 붉은 살처럼 됨.
- 사이트: 뒤통수 입 칸 = 우리 화풍 0.45 4장 → 0.6 4장 → GPT 원본 4장. 지난 그래픽 입(BMC2)·예전 배에 입 그림은 칸에서 내림(사이트 파일 한도).
- 주의: ChatGPT 입력창에 다른 세션(던전 게임 트로피 홀 배경)의 초안이 있었음 → 따로 저장해 두고 새 탭으로 작업, 끝난 뒤 그대로 다시 넣어 둠(보내지 않음).
