## 2. 게임별 핵심 내용

### 2-1. 우마무스메 — Cygames Tech Conference 2021 ★★★
- **구성:** 폴리곤 2만 미만, 재질 6개, 기본 뼈 약 160개, 텍스처 약 20장, 꼭짓점당 뼈 영향 2개.
- **텍스처:** 기본 색 + **그림자 색**(2장) + 제어용 2장(그림자·광택·잘라내기·환경 반사·가장자리 빛 5채널).
- **"텍스처 작업의 대부분은 그림자 마스크 조정"** — 품질에 가장 큰 영향. 형태대로 나오는 그림자로는 애니풍이 안 나와서 사람이 그림자 위치를 정한다.
- **광택도 손으로 모양을 그린다.** 물리적으로 맞는 광택이 애니풍에 맞는다는 보장이 없어서.
- **외곽선:** 면을 뒤집고 노멀 방향으로 부풀린 모델. 외곽선용 노멀과 명암용 노멀이 서로 달라야 해서, 외곽선용 노멀을 따로 계산해 UV 칸에 넣어 둔다. 조정은 손작업(머리카락 다발 경계가 특히 손이 감).
- **얼굴:** 볼·코 그림자를 제어하는 전용 마스크 + 빛 각도 보정.
- **표정:** 눈썹·눈·입 3묶음으로 나눠 만든 뒤 조합. 여기에 위치 옮기기·크기 과장을 더함.
- **표정 보조 (싸게 효과가 큼):** 만화 눈(빙글빙글·반짝), 눈물 3종, 홍조 2단계, **창백해지는 얼굴(파란 그러데이션)**, 땀.
- **눈 하이라이트는 따로 된 텍스처.** 움직이고, 커지고, 떨리고(글썽), 사라지게 할 수 있다.
- **흔들림:** 초기엔 딱딱했고, 엔지니어와 사양을 다시 짜서 고쳤다. 손이 옷을 뚫는 문제는 충돌 판정으로 해결.

### 2-2. 학원 아이돌마스터 — CEDEC 2024 ★★★
- **폴리곤 약 6만.** 머리에 폴리곤을 몰아준다(머리카락 + 얼굴 = 절반 이상).
- **얼굴 면 구조는 전 캐릭터 공통.** 몸은 캐릭터마다 따로 만든다(틀 돌려쓰기 안 함).
- **뼈 321개.** 보조 뼈 약 200개, 전체의 절반이 머리카락. 잔머리 한두 가닥에도 뼈를 넣는다.
- **표정:** 눈·혀는 뼈, 나머지는 얼굴 변형 **100개 이상**. 창백·홍조는 덧붙이는 그림(데칼), 빙글 눈·눈물은 이펙트.
- **카메라 각도에 따라 얼굴 모양을 보정**해 2D처럼 보이게 한다. 코는 정면에서 "점 하나", 옆에서는 코 모양.
- **꼭짓점 색에 7가지 정보:** 외곽선 색·굵기·위치 보정, 재질 번호, 가장자리 빛 마스크 등.
- **텍스처:** 그림자 위치 보정·매끈함·금속·광택 마스크를 담은 제어 텍스처, 명암 색 띠(피부용/그 외), 각도에 따라 색이 변하는 띠.
- 머리카락 흐름은 폴리곤이 아니라 **그림자 위치 보정 텍스처**로 그린다 → UV를 꼼꼼히 편다.
- 자체 제작 흔들림 시스템. 치마 각도를 보고 재킷 흔들림을 제한한다.

### 2-3. 길티기어 Xrd — GDC 2015 ★★★ (애니풍 3D의 교과서)
- 목표: **"3D다움을 전부 죽인다."** 계산에 맡기지 않고 아티스트가 전부 정한다.
- 폴리곤 4만(클로즈업 가능), **노멀맵 안 씀**, 셀 셰이딩은 디자이너가 직접 제어.
- **캐릭터마다 자기 조명.** 무대 조명과 상관없이 얼굴은 항상 밝고 또렷하게.
- 근육선 같은 안쪽 선은 확대해도 깨지지 않게 텍스처·면 경계에 심는다.
- 동작은 보간 없이 **키 자세만** (제한 애니메이션).

### 2-4. 블루 프로토콜 — CEDEC 2020·2021 ★★★
- **외곽선은 화면 후처리**(깊이 + 꼭짓점 색 번호 + 노멀 차이). 이유: 모델 데이터와 노멀 편집 비용 절감. 턱·입·귀·머리카락만 껍데기 방식 보조.
- **노멀맵 안 씀**(압축 잡음이 명암 경계를 망침). 명암은 경계가 뚜렷한 2단.
- **그림자 색은 기본 색에서 표로 변환**(옷용·피부용 표). 처음엔 따로 그렸지만 작업량 때문에 바꿈.
- 점광원은 **노멀을 무시하고 거리만** 적용 → 입체감이 나오지 않게.
- 가장자리 빛은 화면에서 윤곽을 찾아 굵기를 균일하게.
- 얼굴 표정은 **뼈**(화면에 많은 캐릭터가 나와서 변형 방식은 무거움). 눈썹으로 감정을 표현.
- 머리카락 흔들림: 무료 플러그인 Kawaii Physics.
- 교훈: 어린 얼굴은 눈 말고는 "정답 범위"가 좁다 → **눈에 정보를 몰아서 차이를 낸다.**

### 2-5. 원신·붕괴 스타레일·젠레스 존 제로 (miHoYo) ★~★★
- 공식 기술 발표는 배경·콘솔 렌더링 위주이고, 캐릭터 수치는 공개된 것이 거의 없다.
- **커뮤니티 분석으로 알려진 구조** (재현 셰이더 제작자들의 분석, 게임 원본과 100% 같지 않음)
  - 기본 색 텍스처 + **명암 지도**(채널별로 그림자 세기·광택·재질 번호) + **색 띠**(재질별 그림자 색, 낮/밤 줄)
  - **얼굴 그림자 지도:** 빛이 도는 각도에 따라 그림자 모양을 미리 그려 둔 텍스처. 좌우는 뒤집어 씀
  - 명암 경계는 "아주 딱딱하지 않게"(약 0.1), 바깥쪽에 색이 다른 얇은 2차 그림자
  - 머리카락 광택 띠, 금속은 고정 반사 그림(matcap), 스타킹 전용 처리(스타레일)
  - 스타레일 재현 셰이더는 몸·얼굴·얼굴 마스크·머리카락·눈 그림자를 따로 둔다
- **모델 구조 (포럼 분석):** 옷 면의 흐름을 몸 면 흐름에 맞춘다(변형이 깨끗함). "기본 몸에서 모양을 잘라 내고 돌출시켜 만든 것으로 보인다"는 의견.
- **공식 모델 무료 배포:** miHoYo는 원신·스타레일·젠레스(출시 때 18명)의 공식 캐릭터 모델을 MMD 형식으로 배포한다.
  - 규칙(젠레스 기준): 물리·표정 수정 허용 / 재배포 금지 / **부품을 떼어 다른 모델에 쓰기 금지** / 성인물·**고어·공포 작품 사용 금지** / **상업 이용 자제**
  - → **우리 게임에 쓸 수 없다. 구조를 공부하는 참고 자료로만 볼 수 있다.**
- 젠레스 3.0(2026-07)에서 PC 레이 트레이싱 등 그래픽 개편.

### 2-6. 명조 (Kuro Games) ★★
- 대표 인터뷰: 캐릭터 렌더링의 최우선은 **그러데이션**. 시스템 화면의 캐릭터 그러데이션은 캐릭터 팀이 손으로 만든다.
- UE4.26을 크게 개조. 자체 툰 셰이딩을 레이 트레이싱 안에 구현.
- 전문가 분석(Indie-us Games 나카무라): 
  - 머리카락 흔들림은 Kawaii Physics로 보인다. **진짜 대단한 건 뼈 배치와 영향값을 매우 꼼꼼히 넣은 모델러의 손작업.**
  - 눈은 홍채·흰자·하이라이트 3층. 표정·눈 떨림은 **전부 수작업 애니메이션**으로 추정.
  - "기술 위에 장인의 손작업이 쌓인 것. 인력이 느껴진다."

### 2-7. 그 밖
- **명일방주 엔드필드:** 8만~10만 폴리곤. 개발사 말로 "다른 3D 게임 평균의 약 1.5배". Unity 렌더링을 통째로 다시 짬. ★★★
- **소녀전선2:** 애니풍(NPR)과 사실풍(PBR)을 섞음. 머리카락·얼굴의 붓 느낌을 줄여 두 방식의 빛을 맞춤. 스타킹 렌더링 특허. ★★

## 3. 모든 게임의 공통점
1. **노멀맵을 안 쓴다.** 명암은 텍스처(그림자 마스크)와 손으로 고친 노멀로 만든다.
2. **그림자는 계산이 아니라 사람이 정한다.** 그림자 마스크·얼굴 그림자 지도·색 띠.
3. **얼굴은 특별 취급.** 전용 셰이더, 전용 그림자, 손으로 고친 노멀, 항상 밝게.
4. **머리(머리카락 + 얼굴)에 자원을 몰아준다.** 폴리곤 절반 이상, 뼈 절반.
5. **외곽선은 전용 노멀이 필요하다.** 그대로 부풀리면 선이 끊긴다.
6. **표정은 변형 + 싸구려 2D 덧그림의 조합.** 홍조·창백·눈물·만화 눈·눈 하이라이트.
7. **얼굴 구조는 공통, 개성은 눈·머리카락·옷에서.**
8. **마지막 품질은 손작업에서 나온다.** 뼈 배치, 영향값, 그림자 마스크.

## 4. 우리 제작 방식에 반영할 것

### 확인된 것 (방식이 맞다는 근거)
- "얼굴 면 구조 공통 + 개성은 다른 곳에서"는 학원 아이돌마스터가 실제로 쓰는 방식이다 → **공용 마스터 얼굴 방식은 업계 표준과 같다.**
- 품질의 큰 부분이 셰이더·그림자 텍스처·외곽선 노멀이라는 것이 여러 발표에서 반복된다 → **공용 셰이더에 먼저 투자하는 순서가 맞다.**

### 새로 넣을 것 → `ai-3d-pipeline.md` 보강 항목
| # | 배운 것 | 우리 적용 |
|---|---|---|
| 1 | 노멀맵 안 씀 | AI 3D의 노멀맵·구워진 명암은 버린다. 평면 색만 쓴다 |
| 2 | 그림자 마스크가 텍스처 작업의 대부분 | 자동(주름 그늘 계산)으로 초안 → Claude가 규칙으로 보정(목 아래·겨드랑이·옷 겹침) → 사용자 검수. **가장 손이 갈 곳으로 일정에 잡는다** |
| 3 | 그림자 색을 기본 색에서 표로 변환 (블루 프로토콜) | 그림자 색 텍스처를 따로 그리지 않고 피부용·옷용·머리카락용 변환 표를 쓴다 → AI 부품에 바로 적용 가능 |
| 4 | 외곽선 전용 노멀을 UV 칸에 저장 | Blender 스크립트로 부드러운 노멀을 계산해 저장, Godot 셰이더가 읽는다 |
| 5 | 꼭짓점 색으로 외곽선 굵기 조절 | 얼굴 안쪽·눈 주변은 선을 가늘게 또는 없앰 |
| 6 | 얼굴 노멀 편집 + 얼굴 그림자 지도 + 코는 점 | 마스터 얼굴에 한 번만 작업 |
| 7 | 눈 = 홍채·흰자·하이라이트 3층, 하이라이트는 따로 움직임 | 눈 텍스처를 층으로 나눠 그린다. 글썽임·공포로 하이라이트가 사라지는 연출에 쓴다 |
| 8 | 표정 보조: 홍조·**창백**·눈물·땀·만화 눈 | 연애(홍조)와 공포(창백·식은땀·하이라이트 없는 눈)에 그대로 쓴다. 덧그림이라 싸다 |
| 9 | 캐릭터 전용 조명, 점광원은 노멀 무시 | **밤 손전등 장면의 과제:** 손전등은 거리·범위만 적용하고 얼굴 명암은 툰 규칙 유지. 지난 시험에서 얼굴이 하얗게 날아간 문제의 해법 |
| 10 | 머리카락에 폴리곤·뼈의 절반 | AI 머리카락은 다발 단위로 나누고 다발마다 뼈 사슬. 머리카락 흐름선은 텍스처로 그린다 |
| 11 | 가장자리 빛은 화면에서 윤곽을 찾아 균일하게 | Godot 후처리로 구현 |
| 12 | 옷 면 흐름을 몸에 맞춤 (원신) | AI 옷 부품을 다시 짤 때 몸의 면 흐름을 따라가게 한다 (몸 표면에 달라붙이기) |

### 목표 수치 [작업값]
우리 게임은 PC 전용이고 화면에 캐릭터가 1~3명이다. 모바일 게임보다 여유가 있다.
| 항목 | 목표 | 근거 |
|---|---|---|
| 폴리곤 | 4만~6만 | 길티기어 4만, 학원 아이돌마스터 6만 |
| 머리카락 비중 | 폴리곤의 약 40% | 학원 아이돌마스터 |
| 뼈 | 150~300 (머리카락·옷 흔들림 포함) | 우마무스메 160, 학원 아이돌마스터 321 |
| 텍스처 | 캐릭터당 8~15장 (2K) | 우마무스메 약 20장 |
| 표정 변형 | 100개 이상 | 학원 아이돌마스터 (마스터 1번 후보는 153개) |
| 노멀맵 | 없음 | 공통 |

### 솔직한 한계
- 상위 게임의 마지막 품질은 **대규모 인력의 손작업**(뼈 배치, 영향값, 그림자 마스크, 수작업 표정 애니메이션)이다. 이 부분은 AI와 스크립트로 전부 대신할 수 없다.
- 그래서 우리 목표는 "구조와 셰이더는 같은 방식, 손작업 밀도는 캐릭터 4~6명에 집중"이다.
