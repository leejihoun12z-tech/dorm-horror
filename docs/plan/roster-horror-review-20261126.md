# 디자인 괜찮은 28명 — 겹치는 컨셉 · 공포로 살리기 (2026-11-26, [후보] · 분석만)

사용자 11-26: 디자인상 괜찮은 28명 리스트업(해파리 · 문어 · 하스터(노란 옷, 문어 다리) · 쏙독새 · 황새 · 나방 · 마네킹 · TV 머리 · 우산 요괴 · 도자기 · 구미호 · 강시 · 쇼고스 · 슬라임 · 뒤통수 입(평소엔 평범한 사람) · 악마 · 좀비 · 미라 · 장산범 · 아홀로틀 · 도깨비 · 아이아이 · 팔척귀신 · 빨간 마스크 · 갓파 · 초롱아귀 · 고블린상어 · 저주 인형) → 「비슷한 컨셉인 애들, 공포 게임으로 살리기 어려운 애들」.

판단 기준 = 이 게임의 공포 방식 (`dorm-horror-concept.md`):
- **익숙한 기숙사에서 「다른 점」을 알아채는 이상현상** (8번 출구식) + **기숙사 수칙**
- 낮엔 미소녀 → 밤엔 점점 변이(5단계, 불쾌한 골짜기는 3까지) · 피·고어 거의 없음 · 무서움은 **행동·타이밍**으로
→ 「살리기 쉬움」 = ① 기숙사 안에서 작게 시작하는 이상현상이 있음 ② 수칙 한 줄이 바로 나옴 ③ 고어 없이 무서움

## 2. 공포로 살리기 판정 (◎ 쉬움 · ○ 다듬으면 · △ 어려움)
| 캐릭터 | 판정 | 기숙사 이상현상 (작게 시작 → 커짐) | 수칙 한 줄 |
|---|---|---|---|
| 팔척귀신 | ◎ | 2층 창밖에 모자 챙 → 「포포포」 → 아는 목소리 | 창밖에서 불러도 창문을 열지 말 것 |
| 빨간 마스크 | ◎ | 복도 끝 마스크 쓴 사람 → 「나 예뻐?」 | 「보통이에요」라고 답할 것 |
| 뒤통수 입 | ◎ | 늘 등을 보이고 서 있음 → 등 뒤에서 내 비밀이 들림 | 뒤돌아 서 있는 사람에게 말 걸지 말 것 |
| 마네킹 | ◎ | 복도 마네킹 자세가 어제와 다름 → 볼 때마다 가까워짐 | 마네킹에서 눈을 떼지 말 것 |
| TV 머리 | ◎ | 공용 거실 TV에 없는 방송 → 화면 속 얼굴이 내 방 | 자정 이후 TV를 켜지 말 것 |
| 장산범 | ◎ | 문 밖에서 룸메이트 목소리 → 룸메이트는 내 옆에 | 문 밖 목소리에 대답하지 말 것 |
| 저주 인형 | ◎ | 방문 앞 인형 → 이름표에 내 이름 | 문 앞 인형을 방에 들이지 말 것 |
| 하스터 (노란 옷) | ◎ | 게시판에 없는 연극 공지 → 가면 쓴 관객이 늘어남 | 노란 옷의 연극 대본을 읽지 말 것 |
| 쇼고스 | ◎ | 같은 사람이 두 곳에 → 거울 속 얼굴이 다름 | 같은 사람을 두 번 보면 이름을 부르지 말 것 |
| 강시 | ◎ | 점호 때 숨소리가 하나 부족 → 콩콩 뛰는 소리 | 강시 앞에선 숨을 참을 것 |
| 아이아이 | ◎ | 밤마다 벽을 두드리는 소리 → 문을 두드림 | 노크에 세 번 이상 대답하지 말 것 |
| 초롱아귀 | ○ | 복도 끝 작은 불빛 → 불빛 아래 큰 입 | 작은 불빛을 따라가지 말 것 (입보다 **불빛**을 주인공으로) |
| 도깨비 | ○ | 내기·씨름 제안 → 지면 무언가를 가져감 | 도깨비의 내기에 응하지 말 것 |
| 구미호 | ○ | 해 뜬 날 비(여우비) → 여우 가면 쓴 사람이 늘어남 | 여우비 오는 날 가면 쓴 사람을 따라가지 말 것 |
| 갓파 | ○ | 공용 욕조 물이 줄지 않음 → 발목을 잡는 손 | 인사를 받으면 꼭 고개 숙여 인사할 것 |
| 우산 요괴 | ○ | 비 오는 밤 우산 꽂이에 우산이 하나 많음 → 외다리로 뜀 | 남는 우산을 펴지 말 것 |
| 미라 | ○ | 바닥에 금빛 모래 → 붕대가 문틈으로 들어옴 | 붕대를 감아 주지 말 것 |
| 악마 (계약) | ○ | 서명란이 빈 서류가 책상에 → 내 서명이 되어 있음 | 아무 서류에도 이름을 쓰지 말 것 |
| 나방 (올빼미나비) | ○ | 방 불빛에 날개 눈무늬가 창에 붙음 → 눈이 깜빡임 | 밤에 창가 불을 켜 두지 말 것 |
| 쏙독새 | ○ | 창밖 나뭇가지가 하나 늘어남 → 가지가 눈을 뜸 | 창밖 나뭇가지를 세지 말 것 (입 대신 **위장**) |
| 해파리 | △ | 몸이 비침 · 쏘임 — 기숙사 이상현상으로 작게 시작하기 어려움 | (샤워실 물에 비치는 것?) |

| 슬라임 | △ | 귀엽고 흔함 · 쇼고스와 겹침 | (배수구에서 올라오는 것으로 비틀면 ○) |
| 아홀로틀 | △ | 웃는 얼굴·재생 — 귀여움이 강함 | (잘라도 다시 자람 = 신체 공포라 수위 주의) |

| 도자기 (킨츠기) | △ | 깨질까 봐 무서운 쪽(본인의 공포) — 플레이어를 무섭게 하기 어려움 | (금 간 틈으로 다른 얼굴이 보임으로 비틀면 ○) |
