# 기숙생 1 — 흡혈귀 디자인 (새 게임 아트)

_작성: 2026-11-20 · 아트 채팅 · 상태: 전체 [후보] · 사용자 지시: "캐릭터를 먼저 만들고 배경은 거기에 맞게"_
_기준: `dorm-horror-concept.md` §4(두 얼굴 규칙)·§5(변이 5단계)·§6(흡혈귀 줄) · `art-bible.md` §2_
_배경 그림체(시안 A·B·C)는 캐릭터가 나온 뒤 캐릭터에 맞춰 다시 고른다._

---

## 1. 왜 흡혈귀부터
| 이유 | 설명 |
|---|---|
| 3D로 옮기기 쉬움 | 사람 몸 + 옷 + 작은 인외 부위(송곳니·귀). 슬라임(반투명 몸)·라미아(뱀 하반신)보다 AI 3D 관문 1을 통과하기 쉽다 |
| 밤 장치가 바로 게임이 됨 | 거울 = 기숙사 곳곳에 있는 물건(세면대·현관 전신 거울). 이상현상 = 부품 바꾸기 원칙에 딱 맞음 |
| 연애·공포 대비가 큼 | 낮엔 졸리고 허당인 아가씨 → 밤엔 눈을 깜빡이지 않는 "거울 속 그녀" |

## 2. 고정 설정 (concept §6 그대로)
- 성인 여성, 대학 기숙생(20대 외형). 낮잠이 많은 고귀한 아가씨. 피를 보면 기절.
- 고민: **거울에 안 비쳐서 자기 얼굴을 모른다.** 남이 말해 주는 자기 모습만 안다.
- 밤 변이: ① 거울에만 비침 ② 거울 속 그녀가 먼저 움직임 ③ 거울 밖으로 나온 "다른 그녀" ④ 모든 거울이 그녀의 눈
- 해결 열쇠: 관리자가 그려 준 초상화

## 3. 낮 디자인 3안 (하나 고르기)
속성 4겹 = 종족 × 시대·기술 × 성격 갭 × 디자인 집착 포인트. **집착 포인트(낮의 매력)가 그대로 밤의 공포가 된다.**

| | V1 졸린 고딕 아가씨 | V2 자취생 흡혈귀 | V3 옛 귀족 영애 |
|---|---|---|---|
| 한 줄 | 늘 반쯤 감긴 눈의 고딕 드레스 아가씨 | 햇빛 막는 큰 후드티 + 선글라스, 자취 생활형 | 높은 옷깃 망토의 옛 귀족, 회중시계 |
| 시대·기술 | 현대 대학생 + 고딕 옷 취향 | 현대(자외선 차단 옷·암막 커튼 굿즈) | 18~19세기 귀족 그대로 기숙사에 옴 |
| 성격 갭 | 품위 있게 말하는데 서서 존다 | 쿨한 척하는데 피 보면 기절 | 고상한데 요즘 물건을 하나도 모름 |
| **집착 포인트 (낮)** | **졸린 반달눈** + 길게 땋은 은발, 검은 큰 리본 | **소매가 손을 덮는 큰 후드** (소매 손) | **목을 감싼 높은 옷깃** |
| 그게 밤에는 | 눈을 **한 번도 깜빡이지 않고 크게 뜬** 거울 속 그녀 | 소매가 바닥까지 늘어지고 안이 비었는데 손톱 소리 | 옷깃이 열리면 목에 **거울 조각이 박힌** 자국 |
| 거울 장치와 | ◎ 눈 = 거울 4단계 "모든 거울이 그녀의 눈"과 바로 이어짐 | ○ | ○ |
| 다른 기숙생과 겹침 | 구체관절 인형(고딕·인형풍)과 조금 겹침 → 색으로 나눔 | 안드로이드(쿨데레)와 성격 겹침 | 겹침 적음 |
| 추천 | **추천** | | |

**추천 V1:** 낮의 매력(졸린 눈)과 밤의 공포(깜빡이지 않는 눈)가 같은 부위라 규칙 2를 가장 잘 지킨다. 얼굴은 4단계까지 남긴다(규칙 5) — 3단계까지는 "눈만 다른" 같은 얼굴이 가장 무섭다.

### 3-2. 레퍼런스 반영 (2026-11-20, `char-refs-20261120.md`)
- V1~V3는 레퍼런스를 받기 전 안이라 인외 훅이 약하다(사람 + 송곳니). 레퍼런스 규칙 R1(훅 하나)·R3(인외를 소품처럼)·R4(눈 장치)를 넣은 **V4 [후보, 추천]**: 깨진 손거울 조각을 머리 장식·귀걸이로 단다(자기 얼굴을 찾으려 모았지만 아무것도 안 비침). 색 검정·와인·은 + 붉은 눈. 밤에는 조각마다 그녀의 눈이 비치기 시작 → 몸에 거울 금.
- GPT 요청문(§6)은 6명 구성이 정해진 뒤 V4 기준으로 다시 쓴다.

## 4. 밤 변이 = 같은 모델 + 무엇을 바꾸나 (V1 기준, 규칙 6)
| 단계 | 화면 | 3D에서 바꾸는 것 |
|---|---|---|
| 0 평상 | 졸린 반달눈, 눈 하이라이트 있음 | 없음 |
| 1 위화감 | 낮 대화 중 눈 하이라이트가 가끔 꺼짐 · 밤엔 세면대 거울에만 그녀가 비침(실제 자리엔 없음) | 눈 하이라이트 끄기 · 거울 속에만 모델 그리기 |
| 2 부분 변형 | 거울 속 그녀가 내 움직임보다 먼저 고개를 돌림 · 눈을 크게 뜸 | 거울 속 모델에만 다른 동작 · 눈꺼풀 모양 키 |
| 3 신체 공포 | 거울 밖으로 나온 "다른 그녀": 좌우 뒤집힌 가르마·리본, 피부에 거울 금(가는 은빛 균열), 깜빡이지 않음, 쫓아옴 | 좌우 뒤집기 · 균열 무늬 셰이더 · 눈 깜빡임 끔 |
| 4 완전 변이 | 기숙사 모든 거울·유리창에 그녀의 눈 하나씩 · 얼굴 절반이 거울처럼 깨져 비침 | 거울 재질에 눈 그림 · 얼굴 절반 거울 셰이더 |
| ✦ 해방 | 초상화를 받고 처음으로 자기 얼굴을 앎. 리본 하나를 관리자 색으로 바꿔 맴 | 리본 색 바꾸기 |

## 5. 만들 그림 순서
1. **낮 디자인 시안 3장** (V1·V2·V3 전신 한 장씩) → 사용자 고르기 ← 지금
2. 고른 안: 전신 삼면도(앞·옆·뒤) · 표정 7종(기본·웃음·졸림·부끄러움·놀람·기절·화남)
3. 밤 1~4단계 시안 (같은 실루엣 위에)
4. 해방 모습
5. 3D 관문 1 (Meshy·Tripo 무료판)

## 6. GPT 요청문
_규격: 던전 게임 `docs/art-gpt-request-spec.md`(한 요청 한 컷, 생성·재생성만). 새 GPT 창에서 ① 규칙 → ② 시안 요청을 한 장씩._

### ① 새 창 첫 메시지 (규칙)
```
[작업 규칙 — 기숙사 미연시 캐릭터 디자인 시안]

너의 역할: 내가 요청한 캐릭터 그림 1장만 그린다. 설명·검수·상태 보고는 하지 마. 결과 그림만 주면 된다.

[그림체 — 모든 그림에 항상]
- 요즘 서브컬처 3D 애니 게임의 캐릭터 설정화 느낌. 셀 채색(밝은 면 + 그림자 1단), 깨끗한 외곽선, 맑은 색.
- 얼굴은 큰 눈, 또렷한 하이라이트, 작은 코와 입. 성인 여성(20대 대학생) 비율, 8등신에 가까운 날씬한 몸.
- 3D 모델로 옮길 디자인이라 실루엣이 또렷하고, 장식은 크고 덩어리 있게. 잔무늬·작은 장신구를 너무 많이 넣지 마.

[출력 — 모든 그림에 항상]
- 그림 1장에 인물 1명, 전신 정면, 머리끝부터 발끝까지 잘리지 않게. 위아래 여백 충분히.
- 자세: 똑바로 서서 두 팔을 몸 옆에 자연스럽게 내림. 소품은 지시한 것만.
- 무늬 없는 밝은 회색 단색 배경. 바닥 그림자·빛 효과·글자·번호·서명 없음.

[요청 받는 방식]
- "[캐릭터] [옷] [머리] [포인트] [색]" 형식으로 요청한다. 적힌 대로 그리고, 요청에 없는 인물·소품을 더하지 마.

이해했으면 "준비됨"만 답해.
```

### ② V1 졸린 고딕 아가씨
```
[캐릭터] 기숙사에 사는 흡혈귀 대학생. 성인 여성. 품위 있지만 늘 졸린 아가씨. 입을 살짝 다문 채 웃을 때 작은 송곳니 하나가 보임. 귀는 사람보다 조금 뾰족함.
[옷] 현대 대학생이 입는 고딕풍 원피스: 무릎 아래 길이, 검정 + 와인색, 하얀 둥근 옷깃, 긴 소매 끝에 하얀 프릴. 검은 타이츠, 굽 낮은 메리제인 구두. 접은 검은 레이스 양산을 한 손에 들고 끝을 바닥에 댐.
[머리] 허리까지 오는 은백색 머리를 느슨하게 한 갈래로 땋아 앞으로 늘어뜨림. 머리 위에 크고 검은 리본 하나.
[포인트] 눈이 가장 중요: 반쯤 감긴 졸린 반달눈, 진한 붉은 눈동자, 긴 속눈썹. 졸려서 고개가 아주 살짝 기울어짐.
[색] 검정·와인·은백·하양 4색 중심, 눈의 붉은색이 가장 눈에 띄게.
```

### ③ V2 자취생 흡혈귀
```
[캐릭터] 기숙사에 사는 흡혈귀 대학생. 성인 여성. 쿨한 척하지만 허당. 입꼬리 한쪽으로 작은 송곳니가 살짝 보임. 귀는 사람보다 조금 뾰족함.
[옷] 허벅지까지 오는 아주 큰 검은 후드티, 소매가 손을 완전히 덮어 손끝이 안 보임. 후드는 쓰지 않고 등에 내림, 후드 끈 끝에 작은 박쥐 장식. 안에 와인색 짧은 플리츠 치마, 검은 니삭스, 두꺼운 운동화.
[머리] 어깨 위 길이의 은백색 울프컷. 머리 위에 둥근 검은 선글라스를 걸침.
[포인트] 소매가 가장 중요: 손을 다 덮고 끝이 축 늘어진 긴 소매(소매 손). 졸린 반달눈, 붉은 눈동자.
[색] 검정·와인·은백 3색 중심, 운동화만 하양.
```

### ④ V3 옛 귀족 영애
```
[캐릭터] 기숙사에 사는 흡혈귀 대학생. 성인 여성. 수백 년 전 귀족이 그대로 기숙사에 들어온 느낌. 고상하고 조용함. 작은 송곳니, 사람보다 조금 뾰족한 귀.
[옷] 19세기 귀족풍 짙은 남색 드레스(발목 길이)에 어깨를 덮는 짧은 망토. 망토 옷깃이 아주 높게 서서 목을 완전히 감쌈, 옷깃 안쪽은 진홍색. 가슴에 붉은 보석 브로치, 허리에 금색 회중시계 줄. 검은 긴 장갑, 굽 있는 부츠.
[머리] 허리까지 오는 은백색 생머리, 옆머리를 귀 뒤로 넘기고 작은 진홍 머리띠.
[포인트] 높이 선 옷깃이 가장 중요: 턱 바로 아래까지 목을 감싸는 큰 옷깃. 반쯤 감긴 차분한 눈, 붉은 눈동자.
[색] 남색·진홍·은백·금 4색 중심.
```
