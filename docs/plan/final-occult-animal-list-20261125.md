# 최종 오컬트·동물 리스트 (2026-11-25, 그리기 전 · [후보])

사용자 11-25: 「바다·이빨 같은 컨셉(겹침)은 괜찮은데, 외관만 보고 원래 무엇인지 유추할 때 헷갈릴 만한 것들 — 최종 오컬트·동물 리스트 준비」.
→ 판단 기준을 **「생김새만 보고 원래 무엇인지 알 수 있나」 + 「다른 캐릭터와 헷갈리지 않나」** 두 가지로 바꿈. 컨셉 겹침(바다·이빨·소리)은 괜찮음.
카드 자세히: 오컬트 `occult9-cards-20261125.md` · 동물 `animal10-cards-20261125.md` · 프롬프트 `tools/dorm_comfy/cards_occult9.py` · `cards_animals10.py` (이번 고침 반영).

### 1-2. 남기되 서로 헷갈릴 수 있는 쌍 → 이렇게 막음
| 헷갈림 | 왜 | 막는 법 (반영함) |
|---|---|---|
| 팔척귀신 · 우물 원혼 · 일본 유령 | 셋 다 「흰 옷 여자 귀신」 | 실루엣을 셋으로 갈라 둠: 팔척 = **모자 + 키**, 우물 = **얼굴 덮은 머리 + 접시 후광 + 청화 무늬 유카타**(흰 원피스 → 무늬 옷으로 바꿈), 유령 = **삼각 두건 + 다리 없는 안개 꼬리** |
| 흡혈오징어 · 파란고리문어 · 해파리 | 「촉수 달린 바다 소녀」 | 흡혈오징어는 촉수 머리 X → **머리 위 둥근 오징어 지느러미 두 개(귀처럼) + 팔에 붙은 망토 막 + 큰 푸른 눈**, 망토 끝 여덟 갈래만 촉수 |
| 흡혈오징어 · 화장실 셋째 칸 | 둘 다 「붉은 망토」 | 화장실 = 목에 묶은 망토 + 칸 문 배경 · 오징어 = 팔에 붙은 막 |
| 고블린상어 · 넓적부리황새 | 둘 다 「얼굴 위로 길게 튀어나온 모자」 | 고블린상어 후드에 **양옆 작은 눈 + 등지느러미 + 아가미 + 상어 꼬리**를 더해 상어로 읽히게 · 색도 분홍 반투명 vs 청회색 |
| 고라니 · 구미호 · 장산범 | 「동물 귀 소녀」 | 고라니 = **크고 둥근 사슴 귀 + 늘어진 송곳니 + 발굽 손끝** · 머리 이끼 카키(구미호 주황·장산범 흰) |
| 빨간 마스크 · 흡혈오징어 | 붉은 머리 | 둘 다 넣으면 흡혈오징어 머리를 짙은 보라로 |
| 화장실 셋째 칸 | 배경이 없으면 「빨간 치마 단발 소녀」일 뿐 | 타일 칸 문 앞에 선 구도 + 손목에서 풀리는 빨강·파랑 휴지 |
| 갓파 | 접시가 안 보이면 「거북 등딱지 소녀」 | 살짝 위에서 내려다본 구도 → 머리 위 물 접시가 보이게 |
| 선로 귀신 | 상반신 구도면 바퀴가 잘려 「철도 제복 소녀」일 뿐 | 이 캐릭터만 **전신** · 바닥에서 팔로 기는 자세 |

### 1-3. 그대로 괜찮은 것 (상징이 한눈에)
