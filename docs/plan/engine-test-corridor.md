## 2. 같은 조건
- 공간: 복도 6m × 폭 2.4m × 높이 2.6m, 양쪽 방문 4개, 끝에 방화문, 천장 형광등 패널 4개, 신발장 2·소화전함 1·게시판 1 (Godot 시험 복도와 같은 치수 `game/world/test_corridor.tscn`).
- 카툰 재질: 평평한 색 + 2~3단 그림자 + 외곽선 (룩 S49 서브컬처 카툰 렌더가 목표 그림).
- 현실 재질: **무료만** — Megascans(2026-11부터 무료, Fab Standard) · Poly Haven·ambientCG(CC0). 바닥 테라초·벽 페인트·문 나무·금속 소화전함 정도. 목표 그림 = 룩 S50 현실 끝판(초록빛 형광 리미널).
- 섞기: 재질마다 "현실도" 값 하나(0~1) + 빛 색(따뜻한 햇빛 → 초록 형광) + 화면 처리(노이즈·번짐)를 같은 값으로. 물건마다 따로 값을 줄 수 있게(조각씩 현실화, look-exploration §10 C안).
- 종이인형 카드 1장을 복도 가운데 세움(앞 그림만).

## 3. 엔진별 할 일

| 빛 | Lumen(실시간 간접광) · 직사각형 빛 | 구운 라이트맵 + 적응형 프로브 · 직사각형 빛(구움) | LightmapGI(Dynamic) · AreaLight3D |
| 카툰 | 후처리 재질 또는 재질 함수 | Shader Graph 커스텀 조명 | 셰이더 코드 `light()` |

## 5. 결과

### 5-1. Unity 6.3 LTS URP (2026-11-28) — 정지 화면 `img/engine_test_20261128/unity_v2.jpg`
- 만든 것(PC `Projects/dorm-engine-test/DormLookUnity`, 저장소 밖): 셰이더 `Dorm/ToonRealBlend`(현실도 0 = 평평한 색 + 계단 그림자 + 외곽선, 1 = ambientCG 사진 재질 PBR, 전역 값 하나로 섞음) · `DormRealism`(빛 색 따뜻함 → 초록 형광 · 후처리 볼륨 카툰/현실/밤 가중치) · `DormBuilder`(복도 12m 짓기 + 카메라 3자리 × 현실도 0/25/50/75/100 + 밤 2장 = 21장 자동 촬영).
- 재질: Terrazzo008 바닥 · Plaster001 벽 · OfficeCeiling001 천장 · Wood003 문 · PaintedMetal005/012 · 창밖 = Poly Haven urban_courtyard_02.
- **Claude 혼자 된 비율**: 설치 뒤 편집기 클릭 0번. 사용자 몫 = 로그인 2번 · 약관 동의 답 3번 · 관리자 확인 창. 셰이더 오류 1번(Forward+ 조명 반복 매크로가 `inputData` 이름을 요구) → 한 번에 고침.
- 걸린 시간: 프로젝트 만들기 → 21장까지 약 25분(설치·다운로드 제외).
- 관찰(정지 화면, [작업값]): 0 → 100이 끊김 없이 이어짐 · 현실 100은 초록빛 형광 리미널로 꽤 그럴듯함(소품이 상자라 단조로움) · **카툰은 점광원 계단 그림자가 벽·천장에 큰 동심원으로 남아 거슬림** → 카툰 단계는 점광원 대신 면 빛/빛 웅덩이 텍스처로 바꿀 것 · 카툰 밤은 너무 밝고 손전등이 약함 · 현실 밤 손전등은 공포감 좋음.
- 빛은 굽지 않고 실시간만 씀(라이트맵 없이 비교). 굽기를 넣으면 현실 쪽 품질은 오르지만 현실도마다 따로 구워야 함.
