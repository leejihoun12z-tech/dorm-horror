## 고르는 기준
1. **게임 장치를 나눠 맡는다** — 메인마다 다른 공포 장치(시선·대화·소리·점호·반전)를 맡아야 밤이 매번 다르다.
2. 밤 변이의 **대표 변형이 겹치지 않는다**(`night-mutation-cast` §3).
3. **낮 연애 매력**이 뚜렷하다(미소녀 틀 유지).
4. **3D로 만들기 쉽다** — 사람형 몸(데포르메 공용 몸 + 부품). 뱀 하반신·외다리·큰 키 같은 특수 몸은 메인 5명 중 1명 이하.
5. 색·실루엣이 서로 다르다.
6. "사람인 줄 알았는데" 반전 1명(설정: 사람 기숙생 반반쯤).

## A — 추천: 게임 장치를 고르게 나눔
| 메인 | 맡는 공포 장치 | 수칙 한 줄 | 대표 변형 | 3D 난이도 |
|---|---|---|---|---|
| **마네킹** | 시선 — 안 볼 때 움직임 (순찰) | 마네킹에서 눈을 떼지 말 것 | 이목구비 소실·관절 분리 | 쉬움 (진행 중) |
| **빨간 마스크** | **대화 선택지** — "나 예뻐?"에 틀리면 위험 (미연시와 직접 이어짐) | "보통이에요"라고 답할 것 | 찢어진 입·억지 미소 | 쉬움 (사람형 + 마스크) |
| **뒤통수 입** | **반전** — 낮엔 평범한 사람 기숙생처럼 보임 | 뒤돌아 서 있는 사람에게 말 걸지 말 것 | 다른 곳의 입 | 보통 (머리 뒤 부품) |
| **장산범** | 소리 — 문 밖에서 룸메이트 목소리 (점호·방문) | 문 밖 목소리에 대답하지 말 것 | 흉내 얼굴 | 보통 (흰 털·꼬리) |
| **강시** | 점호 — 숨소리 하나 부족, 숨 참기 행동 | 강시 앞에선 숨을 참을 것 | 동태눈·굳은 몸 | 쉬움 (굳은 몸 = 동작이 단순) |
- 좋은 점: 시선 / 대화 / 사람 반전 / 소리 / 숨 — 밤마다 다른 걸 조심해야 한다. 대화 공포(빨간 마스크)가 미연시 시스템과 바로 이어진다.
- **걸리는 점: 마네킹과 빨간 마스크의 색이 겹침**(둘 다 검정·빨강 머리, 빨간 눈). → 빨간 마스크는 **베이지 트렌치 + 빨간 머리 판**(final14 시트 3번)으로 가면 겹침이 줄어듦 [추천].

## B — 공포 세게
마네킹 · **팔척** · 빨간 마스크 · 뒤통수 입 · **우물 원혼**
- 좋은 점: 가장 무섭고 유명한 괴담이 많아 홍보에 강함.
- 걸리는 점: 팔척(큰 키 → 낮/밤 몸 두 벌)·우물 원혼(기어 오는 관절) 3D가 어려움. 긴 흑발 여자 귀신이 둘(팔척·우물). 점호·소리 장치가 빔.

## C — 귀엽고 다양하게
마네킹 · **TV 머리** · 강시 · **도깨비** · **아홀로틀**
- 좋은 점: 낮 미연시가 가장 밝고 다양함(분홍·빨강·검정·파랑). 3D가 쉬움(TV 머리는 머리 부품 교체).
