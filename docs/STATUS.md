- 캐릭터: 낮 = 데포르메 5~6등신 로우폴리 3D로 돌아다님 · 대화 = 2D 일러스트 + 표정 · 밤 괴물 = AI 3D (tech-plan D2-D)

- 캐릭터 만드는 법 [후보]: "Family Time 느낌" — 로우폴리 몸 + 그린 얼굴 텍스처(표정 = 얼굴 그림 바꾸기) + 텍스처에 그려 넣은 선 + 캐릭터당 2~3색 + 옅은 툰(밤 손전등이 먹게). 방법만 가져오고 디자인은 우리 것 (tech-plan §5-4)
